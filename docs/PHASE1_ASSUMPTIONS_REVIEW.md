## 1. A4 气泡沙漏拓扑：假设**成立** ✅（附 2 项机制性发现）

> 原始假设：上锥容量 8-4-8；同 tick 成对种子破坏性干涉 → 归 0 回锚点（MATH_SPEC §4，v1.0 正式设计）

### 1.1 容量与干涉规则在 10000 tick 闭环中的稳定性 —— 通过

| 观测（S1 活跃 10000 tick，主证据） | 数值 |
|---|---|
| 输出/储备/比值界内、无 NaN | 10000/10000 合规，越界 0 |
| 零输出（湮灭产物代理）tick | 2966（29.7%），最长连续零 **12** tick，平均 2.44 → 无堵死、有界拥塞自清 |
| 吞吐（out>0） | 70.3% 持续流动，无永久停滞 |
| 闸门不变量（pass+recycle+reject） | = 10000 = 推入 tick 数（逐次判定成立，复现 CI 单元测试） |
| 台账/时间线环形 | energy_trace_len=512（满）、evo_len=1024（满），正常滚动 |
| 组件级（8-4-8 直接计数） | CI 154 绿内 `long_run_stays_valid_and_bounded` 已覆盖 10000 次独立沙漏长跑（burst 干涉>0、emitted>0、backlog 守恒） |

四场景一致：最长连续零 ≤12、零输出占比 4.9%~29.7%（随物态 pace 的突发率变化，见 1.3）、全程无越界 → **8-4-8 容量与成对湮灭规则在闭环 10000 迭代中稳定，假设成立**。

### 1.2 瓶颈干涉与物态切换的可观测关联 —— **成立，但度量面是"预算态"而非 flow 态**

事件研究（零输出事件 t 后 L tick 内物态切换概率 vs 等量非零 tick 随机基线）：

| 场景 | 物态面 | L=1 P(切换\|零) | P(切换\|非零) | RR | L=3 RR |
|---|---|---|---|---|---|
| S1 活跃 | 预算态 stb | 0.411 | 0.175 | **2.35** | 1.95 |
| S2 渐弱 | 预算态 stb | 0.296 | 0.024 | **12.4** | 11.4 |
| S4 恒流 | 预算态 stb | 0.204 | 0.020 | **10.0** | 12.1 |
| S1 活跃 | flow 态 st | ~0.0007 | ~0.0010 | 0.67（不显著） | — |

结论：
- **瓶颈干涉与物态（预算态）切换存在强可观测关联**（RR 2.4~12×，随场景活跃度升高而稀释但恒 >1）。
- **方向发现（机制修正）**：零输出（成对湮灭）后的切换**压倒性指向"能量重激活"方向**（code ↓，如 Solid→Liquid/Gas、Gas→Energy：S1 计 1216:2、S2 235:0、S4 39:1），而非"向固耗竭"。机制：成对突发发生的同一 tick 必伴随该 tick 的种子吸收（absorb 先于输出结算）；吸收足以抵偿湮灭的 0.4 耗散时，净效应是储备再充、物态被重新点燃。**向固态的耗竭由输入枯竭驱动，不由瓶颈干涉驱动。**
- **度量面发现**：flow 比值态（能量流滚动比阈值 1.05–1.2）在 10⁴ tick 尺度近乎冻结（S1 仅 3 次切换、Energy 占时 99.9%；S2/S3/S4 各仅 3 次、Solid 占时 80–92%），**不是**台账上有分辨率的物态轨迹；A·观察台账的 `budget_code`（预算态）才是可观测物态面。复核判据应以此为准，并建议文档注明两态时间尺度差异（flow 态为慢调度、预算态为快储备）。

### 1.3 鲁棒性附注
S2（输入渐弱）与 S3（饱和骤冷）宏观计数近同（零输出 794、预算态切换 471、占时比一致）：成对突发节奏由**内核内部 `pulse % 7 × 物态 pace`** 决定、储备又长期触顶/触底钳制 → 在饱和/枯竭制度下输出级计数对输入幅度不敏感。这是闭环对输入扰动的鲁棒性表现，非数据错误（两 CSV 输入流不同、md5 不同，均已核验）。

## 2. A5 镜像池 μ=0.95：**需调整** ⚠️（参数值可保持，落点需修正）

> 原始假设：镜像池 μ=0.95、容量 16、静默 5 tick 真空重启 1.0（MATH_SPEC §4，v1.0 正式设计）

### 2.1 静态接入核查（决定性发现）

读 HEAD 277c749 `npb/src/lib.rs` `push()`：主循环对镜像池**只调用 `pool.observe(o)`，从不调用 `pool.tick()`**。即：

- μ=0.95 摩擦衰减、MIN_ECHO 耗尽、静默 5 tick 真空重启 **均未进入 10000 tick 闭环**；
- 闭环中的镜像池退化为"16 深只进不出的最近输出 FIFO"（满则挤旧），无衰减、无重启；
- **A·观察台账的能量耗散曲线因此不含镜像回显衰减分量** —— "用台账直接校验 μ=0.95"的前提在本轮不成立。μ 的衰减语义仅存在于单元测试与 `self_test_digest` 路径。

### 2.2 台账储备耗散实测（系统级代理：EnergyPool stored 曲线）

| 观测 | 数值 |
|---|---|
| S3 饱和 0.8 → 骤冷（0.001） | **2 tick 归零**（0.800→0.357→0.000） |
| S3 0.357 → <1e-4 | **1 tick** |
| S4 饱和 → 恒流 0.28（净耗） | 0.61→0.28→0，**触底 ≤5 tick** |
| S4 逐 tick 相对损失（n=4，净耗步） | median **0.52/tick**；指数拟合等效保留 k≈0.43–0.47 |
| S4 末端 300 tick 稳态 | 储备 0.000、预算态恒 Solid → 无"过慢残留"问题 |

理论对照：

- μ=0.95 单条回显 1.0→1e-6：**~270 tick**（`ln(1e-6)/ln(0.95)`）；
- EnergyPool 纯乘性被动衰减（无 consume，e⁻⁰·¹×0.985=0.8913/tick）：1.0→1e-6 需 **~121 tick**；
- 实测净耗/静默窗口：**≤5 tick 触底**。

### 2.3 判定

- **组件级 μ=0.95 参数合理、可保持**：单条回显 270 tick 寿命既不"过快耗尽"（有 MIN_ECHO 截断 + 有界衰减），也不"过慢残留"（无界衰减 + stall=5 触发重启，天然清零）；
- **假设落点需调整**：主循环未激活镜像池 tick → "μ=0.95 在运行数据中可微调"的前置不成立；而以储备曲线作系统代理，实测等效保留率 ~0.45/ tick、触底 ≤5 tick，与 μ=0.95 的理论寿命（270 tick）相差约两个数量级——**若设计意图是"系统储备按 μ=0.95 级慢耗散"，则实测过快耗尽**。
- 建议（二选一，需发起人裁决）：
  1. **接入**：在 `push()` 闭环补 `pool.tick(None/Some(o))` 调用，使摩擦回显与真空重启真实参与（改法小，但属代码改动，需走流水线）；
  2. **收敛语义**：修订 MATH_SPEC A5 —— μ 仅约束镜像池组件；系统储备衰减由 `natural_return(λ=0.1) + dissipate(×0.985) + consume 结构` 定义，并将"净耗/静默窗口 ≤5 tick 触底"写入作为储备（预算上限）的校准基线。二者并存不互替。

## 4. 边界与风险（诚实声明）

1. **代理而非直读**：沙漏 interference_events/dropped/backlog 无 FFI 导出，A4 运行级证据用零输出事件代理（含空队列兜底 0.0，二者均有界），组件级精确计数依赖 CI 单元测试；如需闭环直读计数，属后续 FFI 扩展（B 类改动）。
2. **样本与输入模型**：34000 tick 均为确定性 LCG 输入模型（无真实用户扰动分布），结论在"闭环演化"语境成立，不代表任意输入分布下外推。
3. **S3/S4 衰减样本少**（储备在净耗制度下 1–5 tick 即触底，天然样本少）——但这本身就是"过快耗尽"的实证；如需连续衰减窗的精细分布，需引入低于 0.28 的恒流梯度扫描（临时脚本可扩，本轮未做）。
4. **A5 的"需调整"不预设方案**：接入 pool.tick 或收敛文档语义二选一，涉及代码/文档改动，按流水线经发起人确认后执行，本轮**零改动**。
