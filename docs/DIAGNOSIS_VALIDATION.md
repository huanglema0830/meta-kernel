# 诊断验证（DIAGNOSIS_VALIDATION）v1.0

> 状态：**v1.0（2026-09-08）** ｜ 链路：用户描述 → 元内核显化 → 云操作系统翻译 → 排查步骤
> 场景：老旧笔记本无法开机（"按电源键，风扇转了，屏幕一直黑"）

## 1. 验证目标

不是让内核"运行"，而是让内核能**帮助诊断设备问题，产生可操作的排查步骤**。
知识库**通过外部接口获取，不本地维护**；未配置时回退内置通用故障模式。

## 2. 端到端实测记录（本机真实网关 127.0.0.1:3000）

### 2.1 路径一 · 外部知识库（配置 endpoint 时）

```
$ META_KNOWLEDGE_ENDPOINT=http://127.0.0.1:9876/diag manifest-journal diagnose 127.0.0.1:3000 "按电源键，风扇转了，屏幕一直黑"

诊断输入 : 按电源键，风扇转了，屏幕一直黑
种子     : 0.5778            ← 元内核：文本指纹 → 确定性扰动种子
来源     : external:http://127.0.0.1:9876/diag   ← 云操作系统：调用外部知识库
排查步骤 :
  1. 屏幕供电链：优先排查 屏线/背光——外接显示器测试（点亮则屏线或面板问题）。
  2. 主板显示输出：若无外接输出，进 BIOS 自检灯/蜂鸣码定位。
  3. 内存/显卡接触：断电清灰重插，单内存条交替测试。
  4. 故障描述已收：按电源键，风扇转了，屏幕一直黑
```

链路拆解（三物种）：
1. **元内核**：文本 → FNV-1a 种子 0.5778 → 真实网关接受并演化（SSE + 快照轮询观测趋势）；
2. **云操作系统**：观测到趋势后，按 `META_KNOWLEDGE_ENDPOINT` 把故障描述（urlencoded 中文正常传递）GET 给外部知识库 → 取回 `{"steps":[…]}`；
3. **空海浏览器（CLI 版输出面）**：把步骤按序号呈现给用户。

外部接口契约：`GET {endpoint}?{query_param}={urlencoded(描述)}` → `{"steps":["…","…"]}`。
一期为 http:// 明文端点（受控内网，与网关部署一致）；TLS 二期。

### 2.2 路径二 · 内置回退（未配置 endpoint 时）

```
来源 : builtin
排查步骤 :
  1. 通用排查（扰动→显化→回融 逐环）：
  2. 1) 注入：写入一条明确念头并确认 push accepted；
  3. 2) 显化：观察显化仪表是否自 0 点亮并向 10–99 推进；
  4. 3) 回融：若停在 99 静默或早退，归档后以新种子再试。
```

内置 8 条模式（按演化趋势匹配）：低能量 / 点亮即回融 / 固化停滞 / 极显早退 /
信号震荡 / 内核无响应 / 正常推进 / 通用逐环。外部调用失败 → 自动回退内置（不断链）。

## 2.3 场景专项验证（键盘 / 台式机无显示 / 充电宝）· 2026-09-08 晚间
三个设备场景经**外部知识库**（专项 mock）全链路实测（文本 → 种子 → 真网关演化 → external 步骤）：

| 场景 | 输入（原文） | 诊断结论（知识库返回，可操作） | 与预期对照 |
|---|---|---|---|
| ① 老笔记本键盘 | 「按键盘时部分按键没有反应，其他按键正常」 | 1) 键盘排线接触不良（重插排线、触点橡皮轻擦）2) 键帽/触点氧化（取下键帽酒精清洁）3) 集中在某几键 → 排线/薄膜断裂，外接键盘验证主板接口 | ✅ 同时命中「键盘排线接触不良」与「键帽触点氧化」两条预期 |
| ② 台式机无显示 | 「台式机开机后显示器无信号，主机风扇正常转。没有显示器信号灯」 | 1) 换线/换接口交叉排除 2) 拔插内存显卡（清金手指）单条交替 3) 核显输出确认显卡 4) CMOS 放电 | ✅ 步骤可操作、由浅入深 |
| ③ 充电宝 | 「充电宝插上充电线有时能充有时不能充，USB口感觉松动」 | 1) USB 口触点氧化/松旷（清理触点）2) 内部焊点虚焊（口松动常见，送修/更换）3) 换线换头交叉验证 | ✅ 「口松动→焊点虚焊」判断合理 |

偏差记录：无原则性偏差；通用场景回退内置（键盘文本英文关键词未命中时走通用三步）。链路稳定复现（三次运行均 external 命中）。

## 4. 局限与下一步

- 本机无真实老旧设备/无法开机样本；故障描述→硬件结论的**正确性**依赖外部知识库内容（云内核只保证链路与翻译，不本地维护知识——符合定位）。
- 外部 endpoint 为 mock（本地验证用）；生产 endpoint 待接入真实知识源（受控内网）。
- 空海浏览器（WASM UI）接诊断结论的展示层：二期（UI 已具备显化日志流/意图区，可直接挂诊断步骤）。
