## 2. 方案 2 与关键实证：火绒没有拦截网关

### 2.1 实验设计（区分两种可能）

"网关进程消失"有两种可能原因，必须区分：
- **A. 会话进程回收**（执行者启动的子进程随会话结束被清理）
- **B. 安全软件拦截**（外部进程终止／阻断监听）

**区分方法**：在**同一个命令内**启动网关并持续轮询——若父进程仍存活时网关卡死，则是 B；若全程稳定，则是 A。

### 2.2 实测数据

```
启动方式：普通用户权限（非管理员），子进程 PID 8364
监控方式：每 5 秒检查一次进程状态 + HTTP 健康检查

  t+05s  ALIVE   health=HTTP 200
  t+10s  ALIVE   health=HTTP 200
  t+15s  ALIVE   health=HTTP 200
  t+20s  ALIVE   health=HTTP 200
  t+25s  ALIVE   health=HTTP 200
  t+30s  ALIVE   health=HTTP 200
  t+35s  ALIVE   health=HTTP 200
  t+40s  ALIVE   health=HTTP 200

存活 8/8 轮，健康检查 8/8 成功
```

### 2.3 结论

1. **火绒没有终止网关进程**（否则 5 秒内就会被杀）。
2. **火绒没有阻断 3000 端口监听**（`/v1/health` 全程 200）。
3. **不需要管理员权限**（普通权限下完全正常）→ **方案 2 不必要**。
4. 之前的"进程消失"= **会话进程回收**（原因 A），与安全软件无关。

### 2.4 补充佐证

- 2026-09-10 已实现过**跨机闭环**：老笔记本经局域网成功回传场域数据到本机网关 →
  说明**入站连接当时也未被拦截**。
- 当时"笔记本连不上"的真因是 **IP 漂移**（`192.168.1.3` → `.4`，DHCP 重分配），
  与安全软件无关；已用动态 bat + 自动扫描解决。

## 3. 为什么"积极拒绝"会发生

| 现象 | 真实原因 | 解决 |
|---|---|---|
| 本机 `127.0.0.1:3000` 连不上 | 网关**进程没在跑**（会话回收） | 双击 `一键启动.bat` / 开机自启 |
| 老笔记本连不上开发机 | 开发机 **IP 漂移**，脚本里是旧地址 | 动态 `run-probe.bat` + 自动扫描网段（已实现） |
| 两者都不是 | — | — |

**没有任何一条指向安全软件。**

## 4. 用户操作指引（修正版）

### 4.1 您真正需要做的（只有两件）

| # | 动作 | 为什么 |
|---|---|---|
| 1 | **双击一次 `一键启动.bat`** | 您启动的进程属资源管理器，**不受会话回收影响**，之后就常驻 |
| 2 | （可选）确认开机自启已开启 | 已注册 `HKCU\...\Run`；想确认就跑一次 `设置-开机自启.bat` |

### 4.2 关于信任区：**不需要折腾**

实证已证明火绒未拦截。**不建议**为此花时间。

但如果您出于安心仍想添加（或日后换了独立版火绒），官方路径是：

| 软件 | 路径 |
|---|---|
| **联想电脑管家**（ThinkPad 定制版 / 新版） | 打开电脑管家 → **安全中心** → **右下角「信任区」** → 添加文件或文件夹 |
| 火绒（独立版） | 主界面 → **防护中心 → 信任区** → 添加文件夹（建议勾选"同时信任子目录"） |
| Windows Defender（如启用） | 设置 → 隐私和安全性 → Windows 安全中心 → 病毒和威胁防护 → 管理设置 → 排除项 → 添加文件夹 |

要添加的目录：`C:\Users\香忆\Desktop\CloudKernel-Run`

> 注：信任区的作用是**让安全扫描跳过该目录**（避免误报误删），它**不解决**"进程随会话被回收"的问题——那是两回事。

### 4.3 关于"卸载联想电脑管家"

**不建议**。理由：
1. 实证表明它**没有造成任何实际阻断**；
2. 它是随机自带组件，卸载可能影响其他联想服务（电源/驱动/固件更新）；
3. 当前问题已有更简单、可逆的解法（双击启动 + 开机自启）。
