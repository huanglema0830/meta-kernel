# L5 语言对照表（L5_TRANSLATION_TABLE）

> 状态：**v0.1（2026-09-09）** ｜ 配套：`docs/L5_DESIGN.md`（L5 号脉层 · 最终版 v2.0）
> 用途：供 `l5_translate.rs` 编译翻译调用（表 = 配置数据，不编译进代码）。
> **约定：对照表在 L5 使用过程中由用户实际验证和补充，不作为固定知识预置。**
> 条目验证状态：`待验证`（示例/占位，未经用户实测确认）→ `已验证`（用户在真实号脉中确认）。
> 缺失词条行为：翻译保留场语言原文并附 `(待补)` 标记，不阻断诊断。

## 1. 九种语言

| 语言 | 范围 |
|---|---|
| 场域语言 | 地、水、火、风（四场本征） |
| 状态语言 | 亢、枯、平（越节律上限 / 越下限 / 节律内） |
| 诊断语言 | 望、闻、问、切（号脉四角度） |
| 三量语言 | 存量、变量、补充增量 |
| 基础代码语言 | 内核层概念：扰动、化合、回融、能量池、显化、萌发…极显 |
| 戒律语言 | 不杀生、不偷盗、不邪淫、不妄语、不饮酒（比丘戒） |
| 对象特征语言 | 硬件 / 软件 / 植物 / 动物 / 地质 等对象特征词汇 |
| 用户通用语言 | 日常表述（"卡了""慢了""没反应""一直转圈"等） |
| 中医语言 | 阴阳、五行生克、虚实寒热 等（对照仅作理解桥，不作医学主张） |

## 2. 条目结构

每条目字段：`seq | 源语言 | 源词条 | 目标语言 | 目标词条 | 语境/条件 | 验证状态 | 备注`

- 可反向（用户通用 → 场域语言，用于把用户描述解析进场）；翻译默认方向 = 场域/状态 → 用户通用。
- "语境/条件"用于一义多译（如 火亢 在 硬件=高占用，在 动物=躁动）。

## 4. l5_translate 调用约定

- 输入：`Diagnosis`（场语言/状态语言构成：fields+pattern+conclusion）+ 当前对象类型（可选）。
- 查表顺序：对象特征语言匹配（若对象类型命中）→ 用户通用语言 → 中医语言（仅说明）。
- 输出：用户可读结论（title/description/cause 的译文版本）；词条缺译保留原文 + `(待补)`。
- 表存储：文本/配置条目（版本化），与代码解耦；更新条目即更新翻译，无需改码。
