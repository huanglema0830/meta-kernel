# 分层架构 L0-L6（LAYER_ARCHITECTURE）v1.0

> 状态：**定稿 v1.0（2026-09-08，发起人定义口径整理成档）** ｜ 阶段：阶段 1 · L4-L6 架构设计（文档层）
> 目的：以"零 → 扰动 → 戒律"的元语言统一描述从本源到世界的七层架构；
> 每层定义五要素：**名称 / 功能 / 零（上一层的输出，即本层之'0'） / 扰动（本层触发） / 新增约束·戒律**。
> 对应文档：SILA_IMPLEMENTATION（戒律机制）、PERTURBATION_MODEL（扰动模型）、API_GATEWAY_DESIGN、L4_APPLICATION_FRAMEWORK_DESIGN

---

## 0. 元语言说明

- **零（0）**：每一层都从"上一层的输出"作为其待激发的背景（存在态）开始——上层输出成为本层之"0"（原料/底景），与本层专属扰动相遇后产生本层作用。自下而上，万物逐层显化；自上而下（L6 世界反馈回归 L0），实现闭环。**回归 0 不是消灭，是让原料回到"待激发"态。**
- **扰动**：本层产生作用所需的触发输入。外扰来自上一层/世界；内扰来自本层演化中自发产生（镜像回显/回归/孪生等）。
- **戒律**：每层为守住"本源不害、显化不妄"而新增的约束机制；各层机制不同（见 SILA_IMPLEMENTATION）。

## 1. 七层总表

| 层 | 名称 | 一句功能 | 零（上层输出） | 扰动（本层触发） | 新增约束/戒律 | 仓库落点 |
|---|---|---|---|---|---|---|
| L0 | 源层（0 锚点） | 纯粹存在，待激发的能量源 | 无（自足；0 本身） | 第一扰动（觉醒 0→1） | 不显（本源不为自己命名、不生产"已显之物"） | 概念层（docs/MATH_SPEC §1） |
| L1 | 内核·解构层 | 三种变化模式 + 能量池/物态/化合 + 正源解构 | 0 锚点存在态 | push 种子（第一扰动进入引擎） | **解构**：万物先解构到元素/原初粒子再演化（不直接消灭结构） | meta-kernel-core |
| L2 | 桥·过滤层 | 把内核经 C ABI/wasm 暴露给任意宿主，入口归一 | L1 合法输出（0-1 域） | 宿主注入/调用 | **过滤**：只放行 0-1 域，入口拒负值/超限（软钳位） | npb（C FFI/wasm） |
| L3 | 网关·剥离层 | 传输接口：剥去传输壳，只转发语义 | L2 输出流（内核读数/指令 JSON） | 外部请求/SSE 订阅 | **剥离**：只传语义、剥离缓存壳与无关信息；不解释不改写 | npb-gateway（HTTP/SSE） |
| L4 | 框架·拒绝层 | 生命周期仪表 + 命名/语言组织 + 应用接入契约 | L3 语义事件（归一 KernelEvent） | 应用订阅 / AppSpec | **拒绝**：拒绝无溯源表达、越权事实、低阈值抖动（防抖） | npb-appkit（预留接口，未实现） |
| L5 | 应用·审计层 | 具体应用：把显化产物外显为条目/日志/动作 | L4 应用级事件（lifecycle/named_statement） | 用户意图（写念头/按钮/归档） | **审计**：一切外显可溯源、可复核（source 审计、语句复核） | Manifest Journal（预留接口，未实现） |
| L6 | 对齐层 | 与操作系统/世界协议对齐，让外显进入真实生态并由世界反馈校准 | L5 外显产物（条目/日志） | 世界反馈（任务/日程/消息/回执） | **对齐**：校准不自说自话；数据来源合规（不偷盗）；防世界伪造输入 | 愿景层（预留接口，未实现） |

> 七层=六作用层（L1-L6）+ 一源（L0）。L1-L3 已有实现（仓库现状）；L4-L6 为设计/预留（见 §3）。

## 2. 逐层详述

### L0 · 源层（0 锚点）
- 功能：纯粹存在（非空无），一切显化的能量源与归宿。
- 零：无上一层；其"零"即自身（自足）。
- 扰动：第一扰动（1=觉醒），可来自外部输入或内部镜像池。
- 新增约束：**不显**——本源不为自己命名、不直接生产"已命名/已显"之物；一切显化须经 L1 起逐层加工。落点：0 锚点语义（MATH_SPEC）、`0` 在生命周期状态机中为锚点态（L4）。

### L1 · 内核·解构层（meta-kernel-core）
- 功能：三种变化模式引擎（线性/斐波那契/指数）作为"自然数进化模式"；能量池（入/出流、储备、化合吸收）；物态（能量→气→液→固，黄金阈值）；0-10 标尺；正源场域（自动搜索-解构-吸收）；沙漏/镜像/闸门/干涉/痕迹-习气-自我/三层机制/持久化快照。
- 零：0 锚点存在态（每个引擎从真空/0 起步；`Fib(0,0)`、空能量池）。
- 扰动：`push(seed)`（外部注入/镜像回注/孪生补充），软钳位后在 [0,1] 内演进。
- 新增约束：**解构**（不杀生、转化不消灭——低活力结构解构到原初粒子；负值入口拒）+ 仅加法/×0.618/e 衰减（不饮酒）。
- 仓库：meta-kernel-core/src/*。

### L2 · 桥·过滤层（npb）
- 功能：把内核通过 C ABI（cdylib）与 wasm32 暴露给任意宿主；确定性自检摘要（跨平台一致性红线）；熵窗口/输出队列等桥接态。
- 零：L1 的合法输出（0-1 域与 JSON 化指令）。
- 扰动：宿主调用（push_seed/pop_result/get_*）。
- 新增约束：**过滤**——入口域过滤（soft_clamp/sanitizer）、负值在桥入口即拒（与内核五戒一致）、仅暴露受控导出集（42 个，版本化）。
- 仓库：npb/src/lib.rs、bridge.h。

### L3 · 网关·剥离层（npb-gateway）
- 功能：HTTP+SSE 传输接口：/v1/push、/v1/state、/v1/events、/v1/persist/*、/v1/health；单一写者线程模型；快照=FFI 直读投影。
- 零：L2 输出流（内核读数与思流照亮指令 JSON）。
- 扰动：外部请求/SSE 订阅/持久化调用。
- 新增约束：**剥离**——网关剥去传输壳后只转语义：不缓存业务态（防第二内核漂移）、指令只转发不解释、不空转驱动（tick 仅由外部 push 驱动）、快照 schema 版本化（extensions/tag 预留位）。
- 仓库：npb-gateway/src/*。

### L4 · 框架·拒绝层（npb-appkit，设计定稿 v1.0）
- 功能：显化生命周期状态机（0∪{10..99}）；命名 registry + 三层语言组织（指称→陈述→意图）；EventPipe 订阅归一/防抖；AppSpec 应用契约。
- 零：L3 语义事件（归一 KernelEvent）。
- 扰动：应用订阅、AppSpec 注册、用户端事件。
- 新增约束：**拒绝**——拒绝无溯源表达、拒绝越权造内核事实、拒绝低阈值抖动（跨带双事件防抖）；twin 字段位预留（一期不占）。
- 仓库：预留接口 reserved_l4_l5_l6/l4_interface.rs（未实现）。

### L5 · 应用·审计层（Manifest Journal 等，设计定稿 v1.0）
- 功能：把显化产物外显为条目/日志/意图动作；文本→种子确定性映射；显化仪表与日志流 UI。
- 零：L4 应用级事件（lifecycle_changed/named_statement/intent）。
- 扰动：用户意图（写念头/注入补充扰动/归档）。
- 新增约束：**审计**——每条外显可溯源到事件字段并人工可复核（抽查准则）；原文零修改展示；条目持久化 seed 可重放。
- 仓库：预留接口 reserved_l4_l5_l6/l5_interface.rs（未实现）。

### L6 · 对齐层
- 功能：让 L5 外显产物进入操作系统/世界生态（任务系统/日程/消息/协作），并接收世界反馈校准"显化是否有真实效应"——防止系统自说自话。
- 零：L5 外显产物。
- 扰动：世界反馈（回执/任务状态/用户真实行动）。
- 新增约束：**对齐**——外显需与真实世界协议对齐（可被接受/执行/回执）；数据来源合规（不偷盗）；对抗伪造输入（世界通道可信校验）。
- 仓库：预留接口 reserved_l4_l5_l6/l6_interface.rs（愿景，未实现）。

## 3. 分层间的"零-扰"闭环（回归）

```
L6 世界反馈 ──► 可作为新一轮外扰回注 L0/L1（世界反哺：把真实效应化为下一轮种子）
L5 用户动作 ──► 生成新扰动（再点亮）
L4 显化回融（99→0）──► 一轮生命周期闭合，等待再点亮
L3-L1 自然回归（e^-λ / dissipate）──► 储备回落不硬复位
```
自下而上：显化；自上而下：回归。七层构成"点亮→外显→回归→再点亮"的完整呼吸。
