# 戒律分层实现机制（SILA_IMPLEMENTATION）v1.0

> 状态：**定稿 v1.0（2026-09-08）** ｜ 对应：LAYER_ARCHITECTURE（L0-L6）、MATH_SPEC（五戒嵌入闸门）、PERTURBATION_MODEL
> 主旨：五戒（不杀生/不偷盗/不邪淫/不妄语/不饮酒）从本源到世界由六层机制逐层守护——
> **L1 解构 → L2 过滤 → L3 剥离 → L4 拒绝 → L5 审计 → L6 对齐**。
> 同一条戒律在不同层以不同强度与形态实现：下层兜底、上层兜全；越靠近世界，机制越"外显可查"。

---

## 1. 总机制-戒律矩阵

| 层 | 机制 | 首要守护 | 形态（内→外） | 落点 |
|---|---|---|---|---|
| L1 | **解构** | 不杀生 / 不饮酒 | 结构转化不消灭；只加法/×0.618/e 衰减 | energy.rs collapse、gate.rs ×0.618、ontology decompose |
| L2 | **过滤** | 不杀生（域）/ 不妄语 | 只放行 [0,1] 合法域；负值入口拒 | sanitizer soft_clamp、npb 入口负值拒、五戒嵌闸门计数 |
| L3 | **剥离** | 不偷盗（状态）/ 不妄语 | 只转语义：不缓存业务态、指令原样转发、schema 版本化 | gateway 投影/单写者/SSE 只转发 |
| L4 | **拒绝** | 不妄语 / 不邪淫（一显一源） | 拒绝无溯源表达、越权事实、低阈值抖动 | LifecycleEngine 防抖、Speaker 可溯源（npb-appkit） |
| L5 | **审计** | 不妄语（外显） | 一切外显可溯源可复核；原文零修改；seed 可重放 | Manifest Journal source 审计 + 抽查准则 |
| L6 | **对齐** | 不偷盗（数据）/ 不妄语（校准） | 与真实世界协议对齐；来源合规；防伪造输入 | WorldAdapter（预留） |

> 结构：下层机制是"结构性护栏"（代码强制），上层机制是"显化性护栏"（外显可查）。五戒在源头是数学约束，在边界是世界契约。

## 2. 逐层机制说明

### L1 · 解构（内核层：结构转化不消灭）
- **不杀生**：不"消灭"结构，只**解构**——低活力（e≤0.2）模式分解到胶粒（层 1），中低活力进入拆解-分析-重编循环，保留可复用的元素与功德（胶粒回收）。
  - 代码锚点：energy.rs `verdict_for`/`collapse_negative`、ontology.rs `decompose`、positive_source.rs `search_and_deconstruct`。
- **不饮酒**：演化只允许三种算子——加法（absorb）、黄金×0.618（闸门拆解）、e 指数衰减（natural_return）；不做其它"调味算法"。
  - 代码锚点：energy.rs `DISSIPATION_DECAY`/`DECAY_LAMBDA` 常量注释、gate.rs ×0.618。
- **（不杀生·入口）负值即拒**：`push(value<0)` 在入口不进入任何下游演化（闸门 rejected 计数）。
  - 代码锚点：npb/lib.rs `Kernel::push` 首行判定、gate.rs `check` 负值分支。

### L2 · 过滤（桥层：入口域纪律）
- 所有跨层输入先过**域过滤器**：soft_clamp 钳到 [0,1]；负值在桥入口即拒并计数（gate_rejected）；无"灰色地带"输入进入内核。
- 对外只暴露**受控导出集**（42 个 get_/set_ 函数，版本化），不加旁路。
- 代码锚点：sanitizer.rs、npb/src/lib.rs 导出面、REQUIRED_EXPORTS 校验（zen/self_test）。

### L3 · 剥离（网关层：只传语义）
- **不偷盗·状态**：网关不得持有"第二份内核状态"——所有对外读数 FFI 直读；SSE 投影只缓存内核读数快照（源=内核，无漂移）。
- **不妄语·转发**：指令 JSON 原样投递（drain 后即发），网关不解释、不补义；快照 schema 版本化 + extensions/tag 预留位（契约稳定）。
- **不空转**：tick 仅由外部 push 驱动（网关不伪造输入推进演化）。
- 代码锚点：npb-gateway/src/lib.rs（Gateway 单写者/投影刷新）、http.rs（SSE 只转发）、API_GATEWAY_DESIGN R1-R5。

### L4 · 拒绝（框架层：显化准入）
- **不妄语**：拒绝任何"无源表达"——命名/陈述必须可回溯到事件字段（source 必填）；拒绝框架侧"代内核发明状态"（生命周期是仪表非内核字段）。
- **不邪淫·一显一源**：一次内核事件至多推进/触发一个显化动作（防抖、跨带双事件）；拒绝低阈值抖动造成的"假显化"。
- 实现载体：npb-appkit（LifecycleEngine 纯函数 + Speaker 模板 + EventPipe 归一）——**预留接口**（reserved_l4_l5_l6/l4_interface.rs）。

### L5 · 审计（应用层：外显可查）
- **不妄语·外显**：每条显化日志 = 命名+陈述+来源；抽查准则（验收 5 条之三：任意 5 条日志可人工比对回事件字段）；原文零修改展示（用户文本不被改写）。
- **seed 可重放**：条目持久化后可按 seed 复现内核演化轨迹（不妄语的反面：一切可验证）。
- 实现载体：Manifest Journal（预留接口 reserved_l4_l5_l6/l5_interface.rs）。

### L6 · 对齐（世界层：真实校准）
- **不偷盗·数据**：外显进入世界生态时数据来源合规（只使用授权/本地产出数据；不窃取他系统状态）。
- **不妄语·校准**：显化产物需能被真实世界"接受/执行/回执"，否则视为未显化（防自说自话闭环）；世界通道加可信校验，拒绝伪造反馈输入。
- 实现载体：WorldAdapter（预留接口 reserved_l4_l5_l6/l6_interface.rs，愿景）。

## 3. 与既有五戒嵌入的关系

MATH_SPEC/摩尼宝珠轮已在**闸门层（内核侧）**嵌入五戒（负值拒=不杀生；镜面只读+胶粒回收=不偷盗；一输入一响应=不邪淫；Pass 原样=不妄语；仅加法/×0.618/e 衰减=不饮酒）。本文件把同一精神**外延到六层机制**：
内核侧五戒=数学/结构保证（L1-L2）；世界侧六机制=显化/契约保证（L3-L6）。二者同源：**守本源不害、守显化不妄**。
