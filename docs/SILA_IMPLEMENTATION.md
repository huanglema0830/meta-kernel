> 状态：**v1.2（2026-09-14，L5 三戒修正 + 诊断层命名）** ｜ 基础：v1.1（层号归位 · 方案 A）、v1.0（2026-09-08）

> 主旨：五戒（不杀生/不偷盗/不邪淫/不妄语/不饮酒）从本源到世界由六层机制逐层守护——
> **L1 解构 → L2 过滤 → L3 剥离 → L4 拒绝 → L5 诊断 → L6 对齐**。
> 同一条戒律在不同层以不同强度与形态实现：下层兜底、上层兜全；越靠近世界，机制越"外显可查"。

>
> **v1.2 变更**：L5 层名 **号脉层 → 诊断层**（"号脉"为功能描述）；三条戒律修正——

## 1. 总机制-戒律矩阵

| 层 | 机制 | 首要守护 | 形态（内→外） | 落点 |
|---|---|---|---|---|
| L1 | **解构** | 不杀生 / 不饮酒 | 结构转化不消灭；只加法/×0.618/e 衰减 | energy.rs collapse、gate.rs ×0.618、ontology decompose |
| L2 | **过滤** | 不杀生（域）/ 不妄语 | 只放行 [0,1] 合法域；负值入口拒 | sanitizer soft_clamp、npb 入口负值拒、五戒嵌闸门计数 |
| L3 | **剥离** | 不偷盗（状态）/ 不妄语 | 只转语义：不缓存业务态、指令原样转发、schema 版本化 | gateway 投影/单写者/SSE 只转发 |
| **L4** | **拒绝**（场域戒律） | 不非时食 / 不捉持 | 场域变量偏离本底场 ≥3 维 → 拒绝进入 L5，且**丢弃不缓存** | `meta-kernel-core/src/l4/`（dimension/threshold/l4_gate/l4_router） |
| **L5** | **诊断**（场域诊断 · 号脉） | 不杀生 / 不偷盗 / 不邪淫 / 不妄语 / 不饮酒 | 只读不干预、结论不缓存、**四场观察+单一诊断**、可溯源（**含哈希链**）、判定只用对象自身场（**翻译层可引入词汇表**） | `meta-kernel-core/src/l5_*.rs`（senses/baseline/compare/diagnosis/translate/router + 语境模块） |
| L6 | **对齐** | 不偷盗（数据）/ 不妄语（校准） | 与真实世界协议对齐；来源合规；防伪造输入 | WorldAdapter（`archive/reserved-interfaces/l6_interface.rs`，愿景） |

> 结构：下层机制是"结构性护栏"（代码强制），上层机制是"显化性护栏"（外显可查）。五戒在源头是数学约束，在边界是世界契约。

### 1.1 应用侧规则（属产品形态，不占层号）

应用框架与参考应用各有自己的准入/审计规则，它们**继承 L4/L5 的戒律精神，但不是 L4/L5 本身**：

| 产品形态 | 规则 | 载体 |
|---|---|---|
| **应用框架**（npb-appkit） | **不妄语**：拒绝无溯源表达（命名/陈述必须回溯到事件字段）｜**不邪淫·一显一源**：一次事件至多推进一个显化动作（防抖、跨带双事件） | `npb-appkit/`（LifecycleEngine / Speaker / EventPipe） |
| **参考应用**（Manifest Journal） | **不妄语·外显**：每条日志 = 命名+陈述+来源；原文零修改；抽查准则｜**seed 可重放** | `manifest-journal/` |

## 2. 逐层机制说明

### L1 · 解构（内核层：结构转化不消灭）
- **不杀生**：不"消灭"结构，只**解构**——低活力（e≤0.2）模式分解到原初粒子（层 1），中低活力进入拆解-分析-重编循环，保留可复用的元素与功德（原初粒子回收）。
  - 代码锚点：energy.rs `verdict_for`/`collapse_negative`、ontology.rs `decompose`、positive_source.rs `search_and_deconstruct`。
- **不饮酒**：演化只允许三种算子——加法（absorb）、黄金×0.618（闸门拆解）、e 指数衰减（natural_return）；不做其它"调味算法"。
  - 代码锚点：energy.rs `DISSIPATION_DECAY`/`DECAY_LAMBDA` 常量注释、gate.rs ×0.618。
- **（不杀生·入口）负值即拒**：`push(value<0)` 在入口不进入任何下游演化（闸门 rejected 计数）。
  - 代码锚点：npb/lib.rs `Kernel::push` 首行判定、gate.rs `check` 负值分支。

### L2 · 过滤（桥层：入口域纪律）
- 所有跨层输入先过**域过滤器**：soft_clamp 钳到 [0,1]；负值在桥入口即拒并计数（gate_rejected）；无"灰色地带"输入进入内核。
- 对外只暴露**受控导出集**（版本化），不加旁路。
- 代码锚点：sanitizer.rs、npb/src/lib.rs 导出面、REQUIRED_EXPORTS 校验（zen/self_test）。

### L3 · 剥离（网关层：只传语义）
- **不偷盗·状态**：网关不得持有"第二份内核状态"——所有对外读数 FFI 直读；SSE 投影只缓存内核读数快照（源=内核，无漂移）。
- **不妄语·转发**：指令 JSON 原样投递（drain 后即发），网关不解释、不补义；快照 schema 版本化 + extensions/tag 预留位（契约稳定）。
- **不空转**：tick 仅由外部 push 驱动（网关不伪造输入推进演化）。
- 代码锚点：npb-gateway/src/lib.rs（Gateway 单写者/投影刷新）、http.rs（SSE 只转发）、API_GATEWAY_DESIGN R1-R5。

### L4 · 拒绝（**场域戒律拒绝层** · v1.1 归位）
- **核心理念**：戒律**不是外部规则，而是场域自身变化的内在边界**；一切判定都在内在完成，不依赖外部输入。
- **不非时食**：七维场域状态 `S=(t,f,a,φ,x,H,τ)` 中，任意 **≥3 维**偏离基线 **> 1.618 倍** → 场域"过量"，**拒绝**变量进入 L5。
- **不捉持**：任意 **≥3 维**偏离基线 **< 0.618 倍** → 场域"枯弱"，**拒绝**。
- **不偷盗·不缓存**：被拒绝的数据**丢弃、不留存**（重复调用结果恒定，无系统状态残留）。
- **不妄语·纯函数**：判定为纯函数——输入（当前场域、基线）决定输出（通过/拒绝），无副作用。
- 实现载体：`meta-kernel-core/src/l4/`（dimension 七维 / threshold 黄金常数 / l4_gate 判定 / l4_router 路由）
- 验证：`docs/L4_VALIDATION_REPORT.md`（6 用例 + 无残留，7/7）

### L5 · 诊断（**场域诊断层（号脉）** · v1.1 归位 / v1.2 三戒修正）
- **不杀生·只读**：诊断**不干预对象**——只读取系统自身的场域扰动，不拆机、不注入、不改动。
- **不偷盗·不占有**：诊断数据**不缓存、不持有**；痕迹对比执行但**痕迹本身不存储**（只读）。
  （例外划界：本底场 = 对象**自身**的地图，非他者数据）
- **不邪淫·四场观察 + 单一诊断**（v1.2 修正，原"一因一果"）：**四场（地水火风）都观察**，但只出**一个主结论**——
  亢优先（多个亢取偏离最大者），无亢取最小枯；复合成因写入 description/cause，**不并列为主结论**。
- **不妄语·可溯源（含哈希链）**（v1.2 修正）：结论含溯源字段（对象/时间/基线/可复现），可复核、可复现；
  **溯源字段增加哈希链**——每次验证入链，历史不可篡改（见 `docs/GENE_LIBRARY_DESIGN.md §2.4`）。
- **不饮酒·边界明确**（v1.2 修正）：**诊断逻辑不引入外部算法**——判定只用对象自身场数据；
  但**翻译层可引入词汇表**（词汇表来自基因库场景公式层，只做语言对照，不参与判定——守不饮酒）。
- 实现载体：`meta-kernel-core/src/l5_*.rs`（六模块：senses / baseline / compare / diagnosis / translate / router）
  + **语境模块**（类型/时间/历史/环境，设计）；本底场升级为**场景公式**（按场景分类）
- 验证：`docs/L5_VALIDATION_REPORT.md`（Q1–Q7 + **真实采集**：老笔记本 `<内网IP>` 实测）

### L6 · 对齐（世界层：真实校准）
- **不偷盗·数据**：外显进入世界生态时数据来源合规（只使用授权/本地产出数据；不窃取他系统状态）。
- **不妄语·校准**：显化产物需能被真实世界"接受/执行/回执"，否则视为未显化（防自说自话闭环）；世界通道加可信校验，拒绝伪造反馈输入。
- 实现载体：WorldAdapter（契约见 `archive/reserved-interfaces/l6_interface.rs`，**尚未实现**）。
- ✅ D2 已裁决（v1.3 · 方案 C）：L6 = **与外界交互层**，含**呈现**（已实现 = 正源浏览器）+ **对齐**（未实现 = WorldAdapter）；
  本节描述的是**对齐**子功能。
- 补充（v1.4）：L6 的**翻译词汇表来自基因库的场景公式层**（见 `docs/GENE_LIBRARY_DESIGN.md §5.3`）。

## 3. 与既有五戒嵌入的关系

MATH_SPEC/摩尼宝珠轮已在**闸门层（内核侧）**嵌入五戒（负值拒=不杀生；镜面只读+原初粒子回收=不偷盗；一输入一响应=不邪淫；Pass 原样=不妄语；仅加法/×0.618/e 衰减=不饮酒）。本文件把同一精神**外延到各层机制**：
内核侧五戒=数学/结构保证（L1–L2）；场域侧=L4/L5 的内在边界与审计纪律；世界侧=L6 契约保证。三者同源：**守本源不害、守显化不妄**。
