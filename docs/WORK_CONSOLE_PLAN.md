> 依据：发起人指令「从"诊断工具"转向"干活工具" + 系统完整实现规划」**并**「实现条件与风险控制」
> 执行原则：① 第一阶段一周内完成 ② **MVP 优先（只做 1–2 个核心功能）** ③ 后续按顺序推进不跳步

## 0. 核心转变

**诊断工具 → 干活工具**。用户打开老笔记本 → 直接打开**空天浏览器** → 在里面**把活干完**；诊断降为**辅助能力**（保留不删）。

---

## 1. 实现原则（本次新增 · 优先于功能列表）

| # | 原则 | 落地要求 |
|---|---|---|
| P1 | **MVP 优先** | 一周内**只做最核心的 1–2 个功能**（本阶段＝**文档 + 文件管理**），**不做全功能** |
| P2 | **兼容性优先** | 只用**最基础的 JS API**（`localStorage` / `JSON` / `document.getElementById` / `addEventListener` / `textContent`）；**不用** ES6+ 语法糖（箭头函数/模板串/`let`-`const` 之外的现代 API）、不用 `fetch`/`Promise`/`IntersectionObserver`/`contenteditable` 之外的现代能力 |
| P3 | **性能优先** | 组件轻量；目标 **内存 < 10 MB、启动 < 1 秒**；每个组件加**性能断言** |
| P4 | **安全优先** | **所有用户输入必须过滤**（XSS / 注入）；渲染一律走 `textContent` 或**转义后**再拼 HTML；**不执行用户输入** |

> **P2 的额外动作**：**先跑兼容性测试，确认支持后再开发**（见 §4.1）。

## 3. 第一阶段（一周 · MVP）：老笔记本能干活

### 3.1 MVP 范围（只做 2 项）

| # | 功能 | 范围（做什么 / 不做什么） | 排期 |
|---|---|---|---|
| 1 | **写文档** | ✅ Markdown 编辑 + **实时预览** + 多文档 + 保存/导出 `.md` + XSS 转义<br>❌ 不做：图片上传、云同步、协同、富文本工具栏 | D1–D3 |
| 2 | **文件管理** | ✅ 本地工作区文件清单（新建/打开/**重命名**/删除/容量统计/下载）<br>❌ 不做：目录树、权限、网盘对接 | D3–D5 |
| — | **诊断（辅助）** | ✅ 保留现有诊断台入口（不新增功能） | D5 |
| — | 查资料 / 表格 / 消息 | ⏸ **待排期**（本阶段不做，避免范围蔓延） | D6–D7 视情况 |

**技术形态**：单页 / **零第三方依赖** / **无框架** / 单文件——这是"比 Edge/Word 更快更省"的根本手段；持久化用 `localStorage`（**离线可用**）。

### 3.2 验收标准（发起人给定 + 可测判据）

| # | 验收项 | 可测判据 | 谁验 |
|---|---|---|---|
| 1 | 打开老笔记本 → 直接打开空天浏览器 | 页面默认视图＝**工作台** | CI 自动目验 |
| 2 | 至少完成 1 个核心任务（写文档） | 新建→输入→预览渲染→保存→重开仍在；**导出 .md 内容正确** | CI 断言 + 用户目验 |
| 3 | 比 Edge/Word 更快更省 | 内存占用 < Edge（同机对比）；启动 < 1s（**数据落盘**） | CI 断言 + 用户目验 |
| 4 | **无 XSS / 注入 / 越权** | 注入 `<script>`/`<img onerror>`/`javascript:` 后**不执行、原文转义显示** | CI 安全断言 |
| 5 | 一周内完成 | §3.1 MVP 两项 ✅ | 发起人 |

### 4.2 需要补充（5 类）

| # | 类型 | 做法 | 落到哪 |
|---|---|---|---|
| 1 | **浏览器兼容性测试** | `compat-test.html`：老笔记本上打开即报告（支持的 API / 浏览器 / 屏幕 / 内存） | 新增页面（本阶段） |
| 2 | **性能测试** | CI 中加**内存/启动断言**（`performance.memory.usedJSHeapSize` + 首屏渲染耗时，设阈值） | `verify.mjs` 扩展 |
| 3 | **安全测试** | XSS / 注入 / 越权用例：写入恶意载荷 → 断言**未执行且被转义** | `verify.mjs` 扩展 |
| 4 | **集成测试** | 端到端：打开 → 建文档 → 编辑 → 保存 → 重载 → 内容仍在 | `verify.mjs` 扩展 |
| 5 | **混沌测试** | 异常输入：空串 / 超长（1MB）/ 纯符号 / 换行 / 同名字段 / 存储满 | `verify.mjs` 扩展 |
