> 状态：**v1.0（2026-09-15 · v0.114）** ｜ 依据：专家源头设计（六层链路 + 分层验收清单）

## 0. 根本问题与结论

老笔记本上 `WebView2Loader.dll` 缺失，暴露的是**架构寄生**：只要依赖 Windows 的 WebView2，
"我们的浏览器"就不是自己的。**结论：转向 WebGPU 场域渲染，不碰系统渲染组件。**

**新链路**：`网页源码 → 场域解析 → 场域状态 → 场域映射 → WebGPU 呈现 → 画面`
关键差异：**不解析 HTML 的"结构"，只解析它的"场域特征"**。

> 说明：WebView2 宿主（v0.113）**保留为降级路径与对照**（不删，避免破坏现有功能）；
> 新增的是一条**不依赖任何 Runtime** 的独立链路。

## 1. ⚠️ 与项目红线的一处冲突及处理（必须先讲清）

| 项 | 内容 |
|---|---|
| **冲突** | 专家建议用 `html5ever`（HTML 解析）+ `lightningcss`（CSS 解析）；但**"内核零依赖"是本项目质量红线**（`用户指令 §五.1`） |
| **我的处理** | **自研零依赖扫描器**（`l1_source_parse.rs`）：只做**结构统计**（标签计数 / 嵌套深度 / 扇出 / 文本字符量 / 媒体与交互密度），**不追求完整 HTML 规范语义** |
| **代价** | 不处理极端畸形 HTML 的完整规范语义（已用畸形/恶意输入测试兜住"不 panic、不越界"） |
| **收益** | 零依赖、可测、跨平台、**可在老笔记本直接跑**（不引入任何外部组件） |
| **若您要求严格照专家方案** | 需要**明确豁免红线**（仅内核侧引入两个 crate）——**等您裁决，我不会自行破线** |

另一处：专家给的饱和曲线是 `1 - e^(-k·x)`，与内核既有 `x/(x+k)` **不同**。
新模块采用专家形式（`saturate`），**旧模块（`l1_field_parse::normalize`）保持不变**，避免破坏既有行为与验收。

## 2. 第一阶段（本周）· 已完成（v0.114）

### 2.1 第一层 · 场域解析器：**源码直解版** — `meta-kernel-core/src/l1_source_parse.rs`（+13 测试）

```text
扫描 HTML 源码（单遍、无递归、零依赖）
   → SourceStats{元素数/文本字符数/最大深度/扇出/标签种数/媒体数/交互数/…}
   扫描 CSS 源码 → CssStats{规则/媒体查询/布局/动效/颜色声明}
   → 四场（饱和曲线归一）
```

| 场 | 公式（可解释、可复现） |
|---|---|
| **地 earth** | `saturate((深度/8) · (最大扇出/4) · 标签多样性, k=2.0)` |
| **水 water** | `saturate(文本字符数 / 元素数, k=0.08)` |
| **火 fire** | `saturate(媒体占比 + 0.3·CSS动效权重, k=3.0)` |
| **风 wind** | `saturate(交互占比 + 0.3·CSS布局/媒体查询权重, k=3.0)` |

**四个验收页面（对应专家检验清单第二层）全部通过**：
纯文本页（水>0.7、火<0.1、风<0.1）｜纯图片页（火>0.7、水<0.1）｜链接密集页（风>0.6）｜结构复杂页（地>0.5）。

**实现中暴露并修掉的三个真实缺陷**（均由验收测试抓出）：
1. **中文被按字节计数**（UTF-8 三字节 → 文本量虚高 3 倍）→ 改为跳过续接字节按**字符**计数；
2. **子节点统计失真**（原实现把"每层当前子数"当成父节点子数）→ 改为**层级栈**统计，并新增 `max_children`（扇出）；
3. **地公式用平均子数会低估深链页** → 改用**最大扇出**（列表/画廊/导航的"宽度"才体现结构复杂度）；
   另修 `saturate` 对 `+INF` 的处理（原实现误判为 0）。

### 2.2 第二层 · 场域映射库：**神经科学初始公式入库** — `l1_mapping.rs`（+8 测试）

- **Gabor**（视觉皮层简单细胞）：`λ = 2π/(地·k+offset)`｜`θ = 风·k·π`｜`σ = 水·k+offset`｜`γ = floor + 火·k`｜`ψ=0`
- **DoG**（视网膜神经节细胞）：`σ_center` 随**火**收窄（更锐），`σ_surround` 随**水**展宽
- **四元组调制**（专家表，连续化避免硬阈值跳变）：
  紧张↑ → `λ×=(1−0.3t)`、`γ×=(1+0.3t)`｜平静↑ → `λ×=(1+0.3c)`、`γ×=(1−0.2c)`｜
  喜欢↑ → `ψ += 0.5·liking`｜安全↑ → `σ×=(1+0.5s)`
- **系数存基因库**（`gabor.*` / `dog.*` 基础公式层）→ **改基因库即改映射**
- `gabor_wgsl()` 产出 WGSL 核文本（含除零保护），供第二阶段直接使用

**第三层验收（映射）全部通过**：极端输入下参数有界无 NaN｜地↑ ⇒ λ 单调递减｜
紧张↑ ⇒ λ 单调递减、安全↑ ⇒ σ 单调递增｜基因库三次读取一致且改库即改映射。

### 2.3 WGSL 设计资产（第二阶段实现用）

- `host/sky-browser/shaders/preprocess.wgsl`：**Stage 1** 场域元素 → 高斯泼溅 2D 参数
  （`Σ' = J·W·Σ·Wᵀ·Jᵀ` 三阶段标准式；Gabor 各向异性尺度；颜色由 `θ+ψ` 决定色相）
- `host/sky-browser/shaders/render.wgsl`：**Stage 3** 屏幕空间四边形 + `exp(-2r²)` 高斯衰减
- 两文件为**设计骨架**（尚未接入 wgpu；第二阶段实现时编译验证）
