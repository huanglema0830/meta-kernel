## 2. L0 · 量子真空态 |0⟩

> ★ 效力与依据（`T-052` 块级标注）：🟡 待复核（首次标记：v0.330 轮） —— **对内／对外**为**编者按同构连缀**（依据：底图 §2.2.3 的 L0↔0 锚点对应 ＋ `docs/LAYER_ARCHITECTURE.md` §2.2.1 L0 行）；**名称／功能**依据主源 §5.1 与既有件 §1（**发起人给定**），**待发起人复核同构是否成立**。

1. **对内**：**本觉**（编者按同构连缀 —— 由「L0 量子真空态 ↔ 0 锚点」对应而来）。
2. **对外**：**照见**（同上，编者按同构连缀）。
3. **含义解释**：**无纠缠的基态**，一切量子操作的**起点**。它不是「什么都没有」，而是**尚未建立任何纠缠**的那一态——对应经典侧的 0 锚点（待激发的纯粹存在）。（比喻）它像一台**尚未接线的仪器**：能效全在，但还没有任何一条关系被建立。★ 底图另记 L0 的经典侧语义为「**本觉／照见**」，本条**只是把该语义按同构搬到量子侧**，不是新定义。
4. **与上下层的关系**：**上承**＝无（自足，为其自身之「零」）；**下接**＝**L1 量子纠缠引擎**（为门操作与纠缠建立提供基态）。（编者连缀 · 🟡 待复核（首次标记：v0.330 轮）；依据：既有件 §1「对应关系」）
5. **实现状态**：❌ **未实现** —— 量子钟整体「**只设计不实现**」；真机落地依赖**量子硬件或其模拟器**。依据：既有件头部诚实边界与 §7、主源 §13.2（「量子钟实现（需量子硬件）」列为**未实现**）。
6. **关键机制**：
   - **基态准备（prepare）**：接口预留为 `prepare()` ——准备 \|0⟩，作为一切门操作的前置。依据：既有件 §5「接口预留」。
   - **「无纠缠」是约束不是描述**：L0 的判据是**未建立任何纠缠**；一旦有纠缠建立，就已经**离开** L0（进入 L1 的作用）。依据：既有件 §1、§2（不邪淫＝「一次只建立一个纠缠关系」的前提是基态未共享纠缠）。
   - **与经典 0 锚点的同构**：经典侧 0 锚点的语义（纯粹存在、不显、自足）**逐条对应**到量子侧。依据：底图 §2.2.3。

## 3. L1 · 量子纠缠引擎

> ★ 效力与依据（`T-052` 块级标注）：🟡 待复核（首次标记：v0.330 轮） —— **对内／对外**为**编者按同构连缀**（依据：底图 §2.2.3 的 L1↔三引擎对应 ＋ §2.2.1 L1 行）；**名称／功能／时间性**依据主源 §5.1 与既有件 §1／§2（**发起人给定**）。

1. **对内**：**生成模型**（编者按同构连缀 —— 由「L1 量子纠缠引擎 ↔ 三引擎」对应而来）。
2. **对外**：**解构**（同上，编者按同构连缀）。
3. **含义解释**：L1 是**量子操作的发生地**：**量子门操作**，以及**纠缠的建立 → 维持 → 解除**。它对应经典侧的三引擎（三种变化模式），但**变化方式由门操作给出，而不是由三条算术公式给出**。（比喻）经典侧像三支不同性格的**笔**，量子侧则像一套**门**——每一道门把状态**转一下**。
4. **与上下层的关系**：**上承 L0**（从量子真空态取得基态）；**下接 L2**（把已建立的纠缠/量子态交给量子通道）。（编者连缀 · 🟡 待复核（首次标记：v0.330 轮）；依据：既有件 §1）
5. **实现状态**：❌ **未实现**（只设计不实现）。**已预留**接口形态：`entangle(pair)`（两体门）、`maintain(t2)`（维持）、`release()`（解除）；**时间尺度参数化**为可注入常量（模拟器可放大到毫秒级便于验证）。依据：既有件 §5。
6. **关键机制**：
   - **建立 → 维持 → 解除**：与经典侧摩尼宝珠链（镜面→闸门→回归）**同构**的三段式；**维持时长由相干时间 T2 约束**。依据：主源 §5.4 对照表、既有件 §1／§2。
   - **门操作严格两体**：**一次操作只涉及一对**（量子五戒之「不邪淫」的量子版本）；**禁止一次操作牵连多体**。依据：既有件 §2。
   - **建立瞬时且不可中断**：纠缠的产生是**瞬时的**（量子五戒之「不杀生」的量子版本），对应设计约束＝**建立操作原子化**。依据：既有件 §2。
   - **痕迹＝纠缠历史路径**：L1 留下的痕迹是**纠缠历史路径**（对应经典侧的历史记录）。依据：主源 §5.4。

### 场景举例

- （编者举例 · 🟡 待复核（首次标记：v0.330 轮））一次门序列：`entangle(pair)` ⇒ `maintain(t2)` ⇒ `release()`；断言「**一次门只作用一对**」（不邪淫）与「**建立瞬时**」（不杀生）。
- （编者举例 · 🟡 待复核（首次标记：v0.330 轮））把**纠缠历史路径**当作痕迹条目（签名＝测量统计特征），从而**复用既有痕迹匹配链**（依据：既有件 §5「与 DNA 的桥」）。

## 4. L2 · 量子通道

> ★ 效力与依据（`T-052` 块级标注）：🟡 待复核（首次标记：v0.330 轮） —— **对内／对外**为**编者按同构连缀**（依据：底图 §2.2.3 的 L2↔摩尼宝珠链对应 ＋ §2.2.1 L2 行）；**名称／功能**依据主源 §5.1 与既有件 §1（**发起人给定**）。

1. **对内**：**归一化**（编者按同构连缀 —— 由「L2 量子通道 ↔ 摩尼宝珠链」对应而来）。
2. **对外**：**千处祈求千处应**（同上，编者按同构连缀）。
3. **含义解释**：L2 的职责是**量子态传输**——把 L1 建立起来的量子态**从一处送到另一处**。对应经典侧的「桥·过滤层」，其「**千处祈求千处应**」在量子侧的读法是：**通道只负责把态送到该去的地方**。（比喻）像一条**只搬东西、不改东西**的传送带。
4. **与上下层的关系**：**上承 L1**（量子纠缠引擎产出的量子态）；**下接 L3**（量子网络接口，向网络分发纠缠）。（编者连缀 · 🟡 待复核（首次标记：v0.330 轮）；依据：既有件 §1）
5. **实现状态**：❌ **未实现**（只设计不实现）。**时间尺度参数化**（普朗克/门时间/相干时间作为可注入常量）为该层**预留**的验证手段之一。依据：既有件 §5。
6. **关键机制**：
   - **只传纠缠本身**：通道**只传纠缠本身，不引入其它媒介**（量子五戒之「不饮酒」的量子版本）；对应经典侧「**不引入外部算法**」的口径。依据：既有件 §2、主源 §5.2／§5.3。
   - **T2 期限即持有期**：一切持有**显式带 T2 期限，过期即解除**——这是经典侧「**不缓存**」在量子侧的表述（量子五戒之「不偷盗」）。依据：既有件 §2。
   - **测量结果对接既有链**：量子态**测量结果**可转为**七维场域采样**，**复用 L3→L4→L5 既有链**（上层无需改动）。依据：既有件 §5「与经典链的桥」。

## 5. L3 · 量子网络接口

> ★ 效力与依据（`T-052` 块级标注）：🟡 待复核（首次标记：v0.330 轮） —— **对内／对外**为**编者按同构连缀**（依据：底图 §2.2.3 的 L3↔痕迹／网络出口对应 ＋ §2.2.1 L3 行）；**名称／功能**依据主源 §5.1 与既有件 §1（**发起人给定**）。

1. **对内**：**把真实需求送给 L2**（编者按同构连缀 —— 由「L3 量子网络接口 ↔ 痕迹／网络出口」对应而来）。
2. **对外**：**找到真实需求**（同上，编者按同构连缀）。
3. **含义解释**：L3 的职责是**量子纠缠分发**——把纠缠**发到网络上的对端**。对应经典侧的「网关·剥离层」，其「**找到真实需求 / 把真实需求送给 L2**」在量子侧的读法是：**分发面负责对齐「谁该拿到这次纠缠」**。（比喻）像一位**只负责分发、不拆封内容**的投递员。
4. **与上下层的关系**：**上承 L2**（量子通道送来的量子态）；**下接**＝量子族的上层（正源操作系统对应层）——**该层在量子族下尚无设计**（底图 §9 记「完全空白」），故本件**下接留空**。（编者连缀 · 🟡 待复核（首次标记：v0.330 轮））
5. **实现状态**：❌ **未实现**（只设计不实现）。依据：既有件头部与 §7；主源 §13.2。
6. **关键机制**：

## 6. 量子五戒（从纠缠角度）

> ★ 效力与依据（`T-052` 块级标注）：🟢 已裁定 —— **五条戒律的量子版本逐字出自发起人给定**（依据：主源 §5.2）。

| **不妄语** | **纠缠传递的关联必须真实** |

## 7. 量子五戒 · 时间尺度映射

> ★ 效力与依据（`T-052` 块级标注）：🟢 已裁定 —— **五戒与时间尺度、物理含义的逐条映射出自发起人给定**（依据：主源 §5.3），与既有件 §2 **一致**。

| 戒律 | 时间尺度 | 物理含义 |
|---|---|---|
| **不杀生** | **普朗克时间** | 纠缠产生是**瞬时**的 |
| **不偷盗** | **相干时间 T2** | 纠缠有**有限寿命** |
| **不邪淫** | **量子门时间** | 一次操作**只涉及一对** |
| **不妄语** | **痕迹唯一** | **不可克隆定理** |
| **不饮酒** | **纠缠媒介** | 只使用**纠缠**作为媒介 |

> 出处：主源 §5.3（表内三列**照录**）；既有件 §2 为同表 ＋ 逐条落地为接口约束。

**本节六要素（模块级）**：（**对内／对外**为编者连缀 · 🟡 待复核（首次标记：v0.330 轮）；**含义解释／关键机制**依据主源 §5.3 与既有件 §2／§5）

1. **对内**：内核自身的**时间秩序** —— 哪一条戒律由哪一种时间尺度来守。
2. **对外**：对外＝**可注入的时间常量**（普朗克／门时间／相干时间可作为参数注入，模拟器可放大到毫秒级便于验证）。

4. **与上下层的关系**：**普朗克时间 ↔ 建立（L1）**／**量子门时间 ↔ 门操作（L1）**／**相干时间 T2 ↔ 维持（L1–L2）**／**痕迹唯一 ↔ 溯源（L3）**／**纠缠媒介 ↔ 通道（L2）**。（编者连缀 · 🟡 待复核（首次标记：v0.330 轮））

  - **不杀生** → **建立操作原子化**（瞬时、不可中断的纠缠生成原语）；

  - **不妄语** → **状态的唯一性由不可克隆定理保证**，痕迹路径不可伪造（溯源天然可验）；
  - **不饮酒** → **通道只传纠缠本身**，不引入其它媒介（对应经典侧「不引入外部算法」）。
