## 1. 三种变化模式引擎（发起人定义，原文）

### 线性变化（Linear）
- 公式：`output = input + 0.01`，强制归一化到 `[0, 1]`
- 含义：惯性、恒常、可预测的平稳消耗

### 斐波那契变化（Fib）
- 公式：`output = (a + b) * 0.5`，其中 `a` 和 `b` 是前两次输出值，强制归一化到 `[0, 1]`
- 含义：生长、自相似递归、基于历史的自我参照

### 指数变化（Expo）
- 公式：`output = input * e^(λ * Δt)`，强制归一化到 `[0, 1]`，
  且当 `output > 0.99` 时强制回退到 `0.5`
- 含义：临界、相变、正反馈爆发与自抑制

## 2. 模糊饱和运算（发起人定义，原文）

- 任何加法运算都采用饱和加法：`a ⊕ b = min(1.0, a + b)`
- 任何输出都强制限制在 `[0, 1]` 区间内

## 3. 0 锚点（发起人定义，原文）

- 系统的初始状态为 0（真空）
- 第一个扰动（1）从外部输入或内部镜像池产生
- 所有运算围绕 0-1 区间展开
