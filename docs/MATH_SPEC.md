## 1. 三种变化模式引擎（发起人定义，原文）

### 线性变化（Linear）
- 公式：`output = input + 0.01`，强制归一化到 `[0, 1]`
- 含义：惯性、恒常、可预测的平稳消耗

### 斐波那契变化（Fib）
- 公式：`output = (a + b) * 0.5`，其中 `a` 和 `b` 是前两次输出值，强制归一化到 `[0, 1]`
- 含义：生长、自相似递归、基于历史的自我参照

### 指数变化（Expo）
- 公式：`output = input * e^(λ * Δt)`，强制归一化到 `[0, 1]`，
  且当 `output > 0.99` 时强制回退到 `0.5`
- 含义：临界、相变、正反馈爆发与自抑制

## 2. 模糊饱和运算（发起人定义，原文）

- 任何加法运算都采用饱和加法：`a ⊕ b = min(1.0, a + b)`
- 任何输出都强制限制在 `[0, 1]` 区间内

## 3. 0 锚点（发起人定义，原文）

- 系统的初始状态为 0（真空）
- 第一个扰动（1）从外部输入或内部镜像池产生
- 所有运算围绕 0-1 区间展开

> **A5 作用域收敛与储备校准基线（v1.1 · 2026-09-07，A·观察演化 v1 实测复核后定稿）**
> 1. **μ=0.95 作用域 = 镜像池组件级**：仅约束 MirrorPool 的**回显摩擦衰减与真空重启**行为，该行为在**单元测试与 `self_test_digest` 路径中生效**；主循环 `push()` 对镜像池只做 `observe`（闭环中镜像池为 16 深只进不出的最近输出 FIFO），μ 衰减与重启不作用于主循环储备。
> 2. **系统储备衰减 = 三源共同定义**：`natural_return`（每次响应后 ×e^(−0.1·t)，波峰回落）＋ `dissipate`（每 tick ×0.985，摩擦热沉）＋ `consume`（输出结算扣减 `0.05+(1−o)·0.35`）。镜像池 μ 与此三者**并存不互替**。
> 3. **储备（预算上限）校准基线**：A·观察演化 v1 实测（2026-09-07，34000 tick 闭环台账）——系统在**净耗/静默窗口 ≤5 tick 内储备触底归零**（饱和 0.8 → 骤冷 2 tick 归零；恒流净耗 ≤5 tick；逐 tick 相对损失中位 0.52、等效保留率 ≈0.43–0.47）。该基线作为储备（预算上限）语义的校准依据，供后续能量语义与界面参数对齐使用。

## 5. 物态引擎切换 · 前提两项（2026-09-18 裁定 · Q8／Q10）

> **来源**：发起人 2026-09-18 指令（基准 v0.199）。**本节为新增**，**不改 §1–§4 任何既有条文**。
> **背景**：§1 定义三引擎，§4 A1 定义引擎输入域 `[0,1]`；`GENE_LIBRARY_DESIGN` §2.1 行61 定义物态阈值（**入/出比**）。
> 两者**量纲不同** ⇒ 本节先把「**用什么口径比较**」与「**怎么把比值喂给引擎**」两件事分别钉住。

### 5.1 输出口径 = **单步口径**（**已裁定**，2026-09-18）

- **定义**：一次 `step(input) → output` 的**读数**，即单次调用的输出值；
  与 `meta-kernel-core/src/linear.rs` 单测 `step(0.5) == 0.51` 的读数口径**一致**（`output = input + 0.01`）。
- **对照口径（未采用）**：稳态口径 —— 同一输入连续迭代 N 步后的收敛值（本处 V2 实测取 N=60）。
- **为什么必须先定口径**：同一裁定规则、同一阈值，跳变幅度**随口径翻转**（V2 实测，2026-09-18）：

| 阈值 | 引擎切换 | 单步口径 | 稳态口径（60 步） | 比值 |
|---|---|---|---|---|
| **0.80** | 线性 → 斐波那契 | **0.010000** | **0.260000** | **26×** |
| 1.05 | 斐波那契 → 斐波那契 | 0.000000 | 0.000000 | 1×（同引擎，不切换） |
| **1.20** | 斐波那契 → 指数 | **0.500000** | **0.166667** | **3×** |

⇒ **口径不定，"要不要加迟滞／插值"这个问题无解** —— 同一个切换在两种口径下相差 **26 倍**。

### 5.2 映射规则「入/出比 → 引擎输入」：**候选方案（待裁定）**

**问题陈述**：物态阈值 `1.2 / 1.05 / 0.8` 判的是**「入/出」比值** `r`（量纲：无量纲比值，域 `(0, +∞)`）；
而引擎输入是**种子** `x ∈ [0,1]`（§4 A1）。**`r = 1.05` 与 `1.2` 落在 `[0,1]` 之外** ⇒ 阈值**无法直接施加**到引擎输入上。
必须补一条映射 `g: r → x ∈ [0,1]`，**或论证"根本不需要映射"**。

**共同约束**（三个候选都必须满足）：
1. 不得破坏 **A1**「系统内一切种子皆 0-1」；
2. `g` 须**单调**（比值越大越"亢"），且四个物态区间**可分辨**；
3. 必须给出**域外行为**（`r > 1.2` 与 `r → 0` 时怎么算）。

#### 候选甲 · 分段线性归一化

| 七要素 | 内容 |
|---|---|
| **评估** | 以 4 个物态边界为节点，把 `r` 分段映到 `[0,1]`（每段约 0.25）；`r > 1.2` 饱和为 1.0，`r < 0.8` 线性落到 0。 |
| **优势** | 分段边界**与物态定义一一对应**（可逐条回指 `GENE_LIBRARY_DESIGN` §2.1 行61）；单调、可逆、可单测。 |
| **劣势** | 节点处**斜率跳变**；新增 4 个刻度常数。 |
| **风险** | 节点跳变**叠加**到引擎切换跳变上（两个跳变同点发生 ⇒ 恶化）。 |
| **机会** | 与 Q10 的"插值"选项天然配套（节点附近做平滑）。 |
| **建议** | 若选甲，**必须与 Q10 的平滑方案同批落地**，不可分开上线。 |
| **等待决策** | 是否接受节点斜率跳变。 |

#### 候选乙 · 对数压缩

| 七要素 | 内容 |
|---|---|
| **评估** | `g(r) = clamp( (ln r − ln 0.8) / (ln 1.2 − ln 0.8), 0, 1 )`；`r ≤ 0` 视为异常（护栏回 0）。 |
| **优势** | **全域连续可导**（无节点跳变）；对 `r` 的**相对变化**敏感，与 §1 指数引擎同构。 |
| **劣势** | 引入 3 个对数常数；`r ≤ 0` 需护栏；物态边界与数值刻度**不再等距**（0.8→0、1.05→0.62、1.2→1.0）。 |
| **风险** | `r` 接近 0 时对数陡峭 ⇒ 低比值区**放大噪声**。 |
| **机会** | 一次性消除节点跳变，可能**直接回答 Q10**（不必再加迟滞）。 |
| **建议** | 若 Q10 倾向"加插值"，这是**最省事的连续化**。 |
| **等待决策** | 是否接受物态边界与数值刻度**不等距**。 |

#### 候选丙 · 物态**只选引擎**、不做数值映射（**本轮推荐**）

| 七要素 | 内容 |
|---|---|
| **评估** | **不引入 `g`**：物态（由 `r` 分档）**只决定用哪个引擎**；引擎输入**仍是本次已有的 0-1 种子**（A1 原样）。 |
| **优势** | ① **不动 A1**、不新增映射常数、不新增量纲；② 与 Q8 裁定「物态→引擎」**语义完全一致**（物态是**选择器**，不是幅度）；③ 改动最小、可逆性最高。 |
| **劣势** | 物态的"**强度**"信息丢失（只知"用哪个引擎"，不知"有多亢／多枯"）。 |
| **风险** | 若上游本意是"物态**也调制幅度**"，丙会**丢语义** —— 须发起人确认。 |
| **机会** | 立刻解冻 Q10／Q11：**没有映射就没有"映射处的跳变"**，只剩"引擎切换点"一个跳变，问题收敛为单变量。 |
| **建议** | **推荐丙**；若发起人确认"物态还需调制幅度"，再叠加甲或乙。 |
| **等待决策** | 物态**是否需要调制幅度**（是 ⇒ 丙不成立；否 ⇒ 丙即终局）。 |

> **本轮立场**：请先回答候选方案**前面那一问** —— 「**物态是选择器，还是调制量？**」
> 这一问不答，甲／乙／丙**无法比较**（它们是**两个不同问题**的答案）。
