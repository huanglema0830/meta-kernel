## 1. 三种变化模式引擎（发起人定义，原文）

### 线性变化（Linear）
- 公式：`output = input + 0.01`，强制归一化到 `[0, 1]`
- 含义：惯性、恒常、可预测的平稳消耗

### 斐波那契变化（Fib）
- 公式：`output = (a + b) * 0.5`，其中 `a` 和 `b` 是前两次输出值，强制归一化到 `[0, 1]`
- 含义：生长、自相似递归、基于历史的自我参照

### 指数变化（Expo）
- 公式：`output = input * e^(λ * Δt)`，强制归一化到 `[0, 1]`，
  且当 `output > 0.99` 时强制回退到 `0.5`
- 含义：临界、相变、正反馈爆发与自抑制

## 2. 模糊饱和运算（发起人定义，原文）

- 任何加法运算都采用饱和加法：`a ⊕ b = min(1.0, a + b)`
- 任何输出都强制限制在 `[0, 1]` 区间内

## 3. 0 锚点（发起人定义，原文）

- 系统的初始状态为 0（真空）
- 第一个扰动（1）从外部输入或内部镜像池产生
- 所有运算围绕 0-1 区间展开

> **A5 作用域收敛与储备校准基线（v1.1 · 2026-09-07，A·观察演化 v1 实测复核后定稿）**
> 1. **μ=0.95 作用域 = 镜像池组件级**：仅约束 MirrorPool 的**回显摩擦衰减与真空重启**行为，该行为在**单元测试与 `self_test_digest` 路径中生效**；主循环 `push()` 对镜像池只做 `observe`（闭环中镜像池为 16 深只进不出的最近输出 FIFO），μ 衰减与重启不作用于主循环储备。
> 2. **系统储备衰减 = 三源共同定义**：`natural_return`（每次响应后 ×e^(−0.1·t)，波峰回落）＋ `dissipate`（每 tick ×0.985，摩擦热沉）＋ `consume`（输出结算扣减 `0.05+(1−o)·0.35`）。镜像池 μ 与此三者**并存不互替**。
> 3. **储备（预算上限）校准基线**：A·观察演化 v1 实测（2026-09-07，34000 tick 闭环台账）——系统在**净耗/静默窗口 ≤5 tick 内储备触底归零**（饱和 0.8 → 骤冷 2 tick 归零；恒流净耗 ≤5 tick；逐 tick 相对损失中位 0.52、等效保留率 ≈0.43–0.47）。该基线作为储备（预算上限）语义的校准依据，供后续能量语义与界面参数对齐使用。
