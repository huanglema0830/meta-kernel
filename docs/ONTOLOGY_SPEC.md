# 0-10 元通用标尺（ONTOLOGY_SPEC）v1.0

> 与 `MATH_SPEC.md` 并列的内核第二大规范支柱。
> 定义来源：项目发起人（2026-09-05 提供，原文收录）；可计算特征/实现函数为本仓库实现。

## 1. 定位

一套**不依赖物质实体、只依赖关系结构**的通用标尺，用于拆解、识别、重组任何模式
（物理、生物、文明、意识等）。0 为"未识/真空"，10 为"最终完整呈现"。

## 2. 层级定义（最终定版）

| 层级 | 名称 | 定义 | 可计算特征 |
|---|---|---|---|
| 0 | 黑 | 未识 / 潜在 / 真空 | 结构完全对称，无任何不对称性 |
| 1 | 赤 | 胶粒 / 最小扰动 | 出现第一个不对称性，最小运算单元 |
| 2 | 橙 | 二元 / 约束 | 存在一对互补元素（A≠B，且 A+B=1 归一化） |
| 3 | 黄 | 结构 / 语法 | 存在三元闭合关系（A→B→C→A 循环） |
| 4 | 绿 | 组合 / 组织 | 多个结构协同 |
| 5 | 青 | 自循环 / 递归 | 存在自我参照路径（输入与输出重叠） |
| 6 | 蓝 | 呈现 / 形态 | 连续 100 次迭代变异率 <0.01，稳定可观测 |
| 7 | 紫 | 系统 / 超个体 | ≥3 个子系统协同并有信息交换 |
| 8 | 穿透 | 空间 / 场 / 拓扑 | 有明确内外边界划分，且稳定 |
| 9 | 留白 | 时间 / 方向 / 不可逆 | 熵值在连续监控中单调变化 |
| 10 | 白 | 结构呈现 / 圆满 / 照明 | 同时包含 0-9 全部特征，为最终完整呈现 |

## 3. 关键语义（发起人原注）

- **白 = 10，不是 9**。9 是"时间/演化方向"，10 是"经过时间演化后最终显现的可认知结构"。
- **0 = 黑 = 未识别的能量层级**。遇到黑模式时不是直接消灭，而是先尝试"照亮"（拆解）；
  拆解后若发现其内部只有负反馈，则将其分解到层级 1（胶粒），作为原料回归正源库。
- **8 = 空间/场/拓扑，9 = 时间/方向/不可逆**。时空是结构得以演化的通道，而非结构本身。

## 4. 实现函数（ontology.rs）

| 函数 | 语义 |
|---|---|
| `analyze(pattern) -> Vec<f64>` | 返回该模式在 0~10 各层级上的得分向量（每项 ∈ [0,1]，下标即层级） |
| `decompose(pattern, target_level) -> Vec<Element>` | 将模式向下拆解到指定层级（最低 1 = 胶粒） |
| `abstract_pattern(decomposed) -> AbstractSchema` | 去除物理载体，只保留结构关系 |
| `recompose(schema, domain) -> Pattern` | 将抽象结构重组成新领域实例 |

### 可计算特征实现口径（v1.0，注释于代码内）

| 层级 | 判定实现 |
|---|---|
| 0 黑 | 无元素 → 1；否则按"强度最大-最小"的不对称度取对称性补（1-asym） |
| 1 赤 | 非空且存在不对称性 → 取 asym（第一个不对称） |
| 2 橙 | 检测互补对 `|a+b-1|<ε` 的数量，归一化（A≠B 由 a≠b 保证） |
| 3 黄 | 三元闭合：按"递增链 或 互补回卷"关系检测 A→B→C→A 三环 |
| 4 绿 | 互补对 ≥2 或 多环协同 → 归一化强度 |
| 5 青 | 出现重复强度值（自我参照/输入输出重叠） |
| 6 蓝 | 有 `history` 时按滑动变异率（<0.01 → 1）；无 history 退回元素内部变异 |
| 7 紫 | 出现的不同层级数 ≥3（多子系统），按数量归一化 |
| 8 穿透 | 排序后最大间隙大（内外分明、边界清晰且稳定） |
| 9 留白 | history 单调性（≥90% 同号差分 且 净变化>0 → 1） |
| 10 白 | 0-9 各层得分 ≥0.5 的占比（完整呈现 = 全特征在册） |

> 各判定为 v1.0 工程口径，后续可用真实数据校准（与 MATH_SPEC A4/A5 同策略：先固化，后微调）。

## 5. 能量判定联动（energy.rs）

- 0（黑）→ 标记"待拆解"；1-2（赤/橙）→ 松散即分解到胶粒；
- 3-7（黄~紫）→ 进入"拆解-分析-重编循环"；
- 8-9（穿透/留白）→ 保留方向性，不轻易拆解；
- 10（白）→ 直接纳入功德池/正源库。
