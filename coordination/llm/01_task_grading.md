# 接口 ①：任务分级（**骨架**｜🔒 半公开）

> **本文件只写「做什么」。** 档位→模型的**映射取值**、判定**阈值**见实现层：
> `{PRIVATE_ASSETS}/llm/01_model_routing_impl.md`
> 归口：**机制 17 拆分机制**｜保密级别：🔒 半公开（C12）

## 一、职责（做什么）

给**一个任务**，判定它属于 **哪一档**，并据此决定**调哪一类模型**。
**三档**（**用户 2026-09-17 定**）：

| 档 | 面向的任务特征 | 档位目的 |
|---|---|---|
| **简单** | 结构化程度高、答案空间小、可机械核验 | **成本与延迟最优** |
| **中等** | 需要一定推理，但路径清晰 | **能力与成本折中** |
| **复杂** | 开放性、需要多步推理或跨材料综合 | **优先能力** |

> ⚠️ **上表只给"特征方向"，不给判据**。**具体判定阈值、以及每档实际映射到哪个模型**属 ⛔，在实现层。

## 二、接口（形态）

```
输入  TaskDescriptor
      ├─ 自然语言描述（必填）
      ├─ 预期输出形态：结构化结构 / 自由文本 / 二者
      ├─ 是否可机械核验（bool）
      └─ 调用方标注的紧急度（可选）
输出  Grade { Simple | Medium | Complex }
       + 判定的**依据**（可复述给用户："因为满足 X，判为 Y"）
```

**三条硬要求**：

1. **必须给依据**（`reason`）—— 只给结论、不给依据 ⇒ **判据不可审计**，不通过。
2. **判定必须是纯函数**（同样的输入给同样的档）—— 不得依赖时钟、随机数、历史累积状态。
3. **分档失败必须可降级不报错**（拿不准时给**更保守的档**，见接口 ②）。

## 三、边界（**不做什么**）

| 不做 | 为什么 |
|---|---|
| **不在内核里判档** | 内核零依赖（**C1**）；且判档需要模型 ⇒ **属宿主侧** |
| **不在此文件写映射表** | 映射表是 ⛔（实现层） |
| **不猜用户未给的档位偏好** | 读不到实现层 ⇒ **如实标注"实现层未就位"**（C5），**不编造** |

## 四、验收（可判定）

| 标准 | 判据 |
|---|---|
| 档位齐三档 | 枚举恰 3 个值，无缺无多 |
| 有依据字段 | 输出结构含 `reason` 且非空 |
| **纯函数** | 同输入连调 10 次，档位**与依据完全一致**（可测） |
| **保守兜底** | 输入缺失/不可解析时返回 **Simple 或 Medium（不得返回 Complex）** —— 偏保守方向可测 |

## 五、与其它两者的关系

- 分档结果 **进入** 接口 ②（降级规则）：档位是降级的**起点**。
- 每次分档**都要**记一条账（接口 ③）：**分档本身也是成本**。
