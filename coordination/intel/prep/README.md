# INTEL · 准备稿目录（`prep/`）

> **用途**：存放**触发条件已满足、状态为「待准备」**的情报的**准备稿**。
> **命名**：`INTEL-00N_prep_<日期>.md`（日期＝`YYYY-MM-DD`）。
> **判据**：**J3** —— 本目录与 `INDEX.md` 状态列**必须对得上**：
> 表中有「**待准备**」而本目录**无对应准备稿** ⇒ **违规**。
> **为什么放一个说明文件而不是空目录**：git **不跟踪空目录** ⇒ 放本文件使 J3 的检查对象**物理存在**（且顺带把"谁来判、怎么判"写清）。
