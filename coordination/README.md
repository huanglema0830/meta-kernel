# 协调文件夹 · 启动引导

每次对话开始，按顺序读以下文件：

1. BASELINE.md — 项目当前状态
2. CONSTRAINTS.md — 硬约束清单（不可破）
3. TEMPLATES.md — 报告格式
4. instructions/ 下最新文件 — 当前任务

读完再动手。

## 文件夹职责

| 文件/文件夹 | 职责 | 维护者 |
|---|---|---|
| BASELINE.md | 项目当前状态的唯一权威描述 | WorkBuddy，每版本更新 |
| CONSTRAINTS.md | 硬约束清单 | 顾问定，WorkBuddy可补充 |
| TEMPLATES.md | 指令与报告模板 | 顾问 |
| instructions/ | 指令归档 | 顾问 |
| reports/ | 报告归档 | WorkBuddy |
| discussions/ | 讨论记录 | 顾问整理，用户审核 |
