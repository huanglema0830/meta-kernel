# 模板活相机制 · 变更记录（TEMPLATES_CHANGELOG）

> **活相机制**：模板（`TEMPLATES.md`）的**固定相骨架**可以变，但不能悄悄变。
> 变更规则（详见 `CHARTER.md` §七）：
> - **新增** → 记入本文件 → **试用 3 轮** → 正式生效（试用期内若不好用可撤销）
> - **调整** → 先在 `OBSERVATIONS.md` 记录"为什么不够用" → 改 `TEMPLATES.md` → 在本文件登记
> - **撤销** → 标注「已废弃」→ 3 轮后移除
> - 任何变更都必须由**用户确认**后生效（对应 C8：硬约束/机制可扩充，但要确认）

---

## 记录格式

```
## [日期] 变更编号 · 类型（新增/调整/撤销）· 状态（试用中/已生效/已废弃）
- 变更对象：TEMPLATES.md §X
- 变更前：
- 变更后：
- 为什么：
- 试用轮次：0/3
- 确认人：
```
