## 二、三层结构与规则

| 层 | 放什么 | 位置 | 加密 |
|---|---|---|---|
| **公开层** | 编号 + **英文名** + 中文功能说明 + 指针 | 仓库内（本文件） | 无 |
| **索引层** | 编号 + 英文名 + **代码代号** + 指针 | **仓库外** | ✅ AES-256-GCM |
| **内容层** | **全拼 + 原名** + 原始内容 + 真实代码路径 | **仓库外** | ✅ AES-256-GCM |

**核心规则**

1. **英文名必须是功能描述型**：禁止拼音转写（例：写成 `foobar123` 这种拼音式占位 ❌）、禁止生僻造词。
   > ⚠️ **本规则的反例必须用"与本表无关的占位串"**——曾经拿某条目的**真实全拼**当反例写进公开层，
   > 等于**在该行泄露原名**（判据当场抓到，已改）。
2. **公开层保留中文功能说明**：中文读者看说明就能懂，无需知道英文怎么念。
3. **代码位置用代号**：如 `CODE-003`；**真实路径只在内容层**。
4. **编号是稳定锚点**：换名**不改编号**，索引层与内容层**不动**。
5. **索引层不得含全拼/原名**：全拼与原名**只在内容层**。
6. **不加密 ≠ 安全**、**加密也 ≠ 安全**：见 §四 的边界说明。

## 三、加密与密钥 ｜**密钥级别：⛔ 机密**（本体／路径／其余一律先按机密）

| 项 | 约定 |
|---|---|
| 算法 | **AES-256-GCM**（**AEAD**：篡改/换文件都会被认证标签拒绝） |
| 密钥 | **32 随机字节**，存**本地**、位于 `PRIVATE_ASSETS` **同级**目录，**绝不进仓库** | ｜**密钥级别：⛔ 机密**（本体／路径／其余一律先按机密）
| 解密时机 | **内部查阅时按需解密、用完即弃**（明文不落盘） |
| 工具 | 仓库外 `{PRIVATE_ASSETS}/tools/terms_crypt.py`（`keygen` / `keycheck` / `keyexport` / `enc` / `dec` / `verify` / `purge`） |
| ⚠️ 不可逆 | **密钥丢失 ⇒ 私有层永久不可读**。生成后**必须离线备份**。 | ｜**密钥级别：⛔ 机密**（本体／路径／其余一律先按机密）

## 四、⚠️ 边界说明（必须说准，不许含糊）

1. **换壳 ≠ 消除**：**git 历史与已推送内容仍可检出**原名（`docs/` 等面实测仍有存量）。
   ⇒ 收益是「**今后新写的不带旧名** ＋ **术语有稳定编号可查**」，**不是**「旧的查不到」。
2. **加密 ≠ 挡住仓库内的原名**：加密只保护**私有层的落盘形态**（防误拷贝 / 云同步 / 备份被读）。
3. **代码代号是"降一层难度"，不是强边界**：源码本身在公开仓库，读者仍可能找到候选实现。
4. **公开层不写全拼**：全拼≈原名的拼音，写出来等于没换。
