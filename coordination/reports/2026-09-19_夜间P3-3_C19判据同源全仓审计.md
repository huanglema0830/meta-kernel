### E-1（F1）—— 4 份剥离实现的实测分歧（**本项最硬证据**）

**方法**：仓库外审计脚本（**不入仓库**），`import` 四个工具模块，用**同一批输入**喂各自的剥离函数，比较输出。

|---|---|---|---|---|---|
| `npb-gateway/src/http.rs`（43,143 字符／1,057 行） | 22,708／602 | 22,708／602 | 23,163／1,057 | 22,708／602 | 3 同（`purity` 因保留行数而异，**预期**） |
| `meta-kernel-core-nostd/src/fmath.rs`（47,795／1,510） | 20,395／**753** | 20,395／753 | 21,152／1,510 | 20,200／**743** | ❌ **`endpoint` 与其余差 195 字符／10 行** |
| `meta-kernel-boot/kernel/src/verify.rs`（33,572／966） | 33,572／966 | 同 | 同 | 同 | ✅ 四者一致（该文件无 `#[cfg(test)]`） |

**B. 构造用例（`#[cfg(test)]` 块置于文件中部）**

```
输入： fn before() {}\n\n#[cfg(test)]\nmod tests { ... }\n\nfn after() { let x = 1; }\n
closure / fidelity / purity  ⇒ 输出**保留** `fn after()`
endpoint                     ⇒ 输出 `'fn before() {}\n\n'` —— **后置代码被丢弃**
```

**C. 逐字比较结论**
- `closure.strip_test(T) == fidelity.strip_test_blocks(T)` ⇒ **True**（**逐字相同**，属"复制出来的第二份"）
- `purity.strip_test_blocks(T) == closure.strip_test(T)` ⇒ **False**（`purity` 用空行占位以**保留行号**，用途正当）
- `endpoint.strip_test(T) == closure.strip_test(T)` ⇒ **False**

**D. 根因定位（`fmath.rs` 的 10 行差从哪来）**

实测该文件有 **3 个** `#[cfg(test)]` 块，花括号配对的跨度分别为：

| 块起始行 | 配对结束行 |
|---|---|
| 744 | 1197 |
| 1201 | 1260 |
| 1265 | 1510 |

- `closure`／`fidelity`（配对语义）⇒ **挖空三个块**，保留块间空隙 ⇒ 753 行。
- `endpoint`（**截断语义**：`txt[:m.start()]`，只保留**第一个** `#[cfg(test)]` 之前）⇒ 743 行，**连带丢弃三个块之间的空隙**（195 字符）。

⇒ **在"测试块都放文件尾部"的现行约定下，两者结果大体等价**；但**一旦生产代码写在测试块之后**，`endpoint` 语义会**静默丢弃**它（构造用例已复现）。**当前实际受影响面**：`endpoint_table` 只解析 `npb-gateway/src/http.rs`（该文件的测试块亦在尾部）⇒ **尚未造成误判**。
