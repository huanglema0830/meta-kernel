## 二、做了什么（两件，属**同一项**：补判据 → 判据当场抓出缺陷 → 处置）

**① 新增 `--selftest`（十一侧 / 共 12 条断言）** —— 全部在**临时目录**里建夹具，**不落真实仓库**：

| 侧 | 断言 | 期望 |
|---|---|---|
| ① | 合规引用 | 错 0 **且**解析到 **2** 处引用（防"空跑也报绿"） |
| ② | 反斜杠写法 | 判红（R16 同族：初版只认 `/`，反斜杠曾整类漏报） |
| ③ | `..` 越出私有根 | 判红 |
| ④ | **写成绝对路径（盘符）** | 判红 ← **本轮红过又转绿的正是这一侧** |
| ⑤ | 指代私有根整体／模板占位 | **不判红、且不计入引用**（防误报，阴性对照） |
| ⑥ | 行内有「示例/反例/待建/模式」标注 | 放行（**必须显式**才放行） |
| ⑦ | 泄漏：**真名盘符** vs **掩码示例** | 真名**必须命中**｜掩码**必须不命中** |
| ⑧ | `[5]` 密钥级别 | 同一次调用内：带 ⛔ 的放行、**无标识的恰好抓 1 行** |
| ⑨a/⑨b | `[6]` 指纹字面量 | 有字面量判红 1；写占位符判 0 |
| ⑩ | `resolve` 三包（**CI 覆盖不到的那一半**） | 目标存在=0｜目标缺失=1｜**私有根落在仓库内=1（点名「结构性隔离」）** |
| ⑪ | **真实仓库锚点** | 回读真实仓库：格式错 **0** 且引用数 **>0**（防"夹具与常量同错"，R64） |

> ⚠️ 样本纪律：⑨ 要求的"16 位十六进制"由 `"0" * 16` **构造**而非写字面量 ——
> 既避免"样本被误当真指纹"，也顺带证明该判据**不依赖被保护对象本身**。

**② 修掉它当场抓出的「死分支」（这是本项的真正收获）**

原判据（修改前）：

```python
clean = re.match(r"[A-Za-z0-9_./\-]*", raw).group(0).rstrip("/")   # ← 字符类里**没有 `:`**
...
if re.match(r"^[A-Za-z]:", clean) or clean.startswith(".."):        # ← 在 clean 上判「盘符」
```

`clean` 由上述字符类产出 ⇒ **`clean` 里永远不可能有 `:`** ⇒ `re.match(r"^[A-Za-z]:", clean)` **恒为 False**，
**是一条永不触发的死分支**。修改：判据改到**未被清洗的原串 `raw`** 上（与同层的 `..` 判据同口径：**涉及"越界/绝对"的判断一律用原串**，清洗只用于"存在性查找"）。

**判据静默失效比判据判红危险得多**（判红有人看，静默无人看）。
