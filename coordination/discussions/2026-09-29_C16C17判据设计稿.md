## 一 · 判据逻辑（**检查什么／什么算违反／怎么判**）

### 1.1 `C16` 侧

| 项 | 设计 |
|---|---|
| **触发** | ★ 文本中出现 **断言词**：`不存在`／`全库无`／`从未`／`没有定义`（**原文四词**） |
| **检查** | ★ **同一段落**（±N 行窗口）内是否出现 **四要素的形态标记**：①「检索式」②「范围…N 份」③「命中…N」④「阳性对照／对照…N」 |
| **违反判定** | ★ **四要素形态标记 < 4 ⇒ 告警** |
| **怎么判** | ★ **相邻窗口内关键词 ＋ 数字共现检测**（**不解析语义**） |

### 1.2 `C17` 侧

| 项 | 设计 |
|---|---|
| **触发** | ★ 文本中出现 **管辖词**（**原文 8 词**）：`虚假声明`／`自相矛盾`／`名实不符`／`形同虚设`／`挂羊头卖狗肉`／`从未`／`全库无`／`底图落后` |
| **检查** | ★ 同段落内是否出现 ①「穷举／查了哪些」②「原文」＋**引用形态（引号/表格两行）** ③ 是否**同时给出 `C16` 四要素** |
| **违反判定** | ★ **缺 ① 或 ② 或 ③ ⇒ 告警** |
| **怎么判** | ★ **同上（形态检测）** |

### 1.3 ★ 两条共同的**降噪机制**（**设计核心**）

```
扫前剔除（复用 T-041 scan_exclude.json 机制，扩 2 层）：
  L1 元标注块        （条文引述、术语定义）      ← 既有
  L2 待裁定段        ← 既有
  L3 问答式          ← 既有
  L4 举例引用段      ← 既有  ★ 取证稿 4 处中 2 处属此层
  L5 讨论式          ← 既有
  ★ L6 【本轮新增】风险/后果描述段（「⇒ 形同虚设」「破了会怎样」）★ 取证稿 4 处中 2 处属此层
  ★ L7 【本轮新增】本判据自身条文（含 8 词表）★ 防自指污染
```
