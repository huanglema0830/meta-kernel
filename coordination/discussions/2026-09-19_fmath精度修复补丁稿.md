## 一、改动清单（逐处：行号 ＋ 旧文 ＋ 新文）

> 行号取自当前 `meta-kernel-core-nostd/src/fmath.rs`（**回读验证**）；**改后行号会漂**，定位**以符号名为准**（R75）。

### 改动 ①：补 `cos` 级数的 `r¹⁴/14!` 项

| 项 | 内容 |
|---|---|
| **位置** | `fn sin_cos_f64` 内的 `c`（**行 218–223**） |
| **旧文（逐字）** | `+ r2 * (-1.0 / 3_628_800.0 + r2 * (1.0 / 479_001_600.0))))));` |
| **新文** | `+ r2 * (-1.0 / 3_628_800.0 + r2 * (1.0 / 479_001_600.0 + r2 * (-1.0 / 87_178_291_200.0)))))));` |
| **数学依据** | `cos r = Σ (−1)ᵏ r^(2k)/(2k)!`；现终止于 `r¹²`（`1/12! = 1/479_001_600`），补**下一项** `−r¹⁴/14!`，而 **`14! = 87,178,291,200`**（**须在改动时逐字复核此常量**） |
| **括号核算** | 新增一层 `r2 * ( … )` ⇒ **右括号必须多一个**（旧 `))))));` → 新 `)))))));`）—— ★ **这是最易写错处**：括号数错 ⇒ 编译失败或**语义静默改变** |
| **附带** | 同步更新**行 191 的 docstring**：`cos` 到 `r¹²` → **`r¹⁴`**；截断误差估值 **< 1e-12** → **< 1e-15** |

**截断误差估算（口径要写清）**：`|r| ≤ π/4 ≈ 0.7854` ⇒ `r¹⁴ ≈ 0.0341`，`0.0341 / 14! ≈ 3.9e-13`（**改前**）；补项后残差量级 ≈ `r¹⁶/16! ≈ 0.021/2.09e13 ≈ 1.0e-15`。
⇒ **改前截断误差 ≈ 3.9e-13，约为 f64 ε（2.2e-16）的 1800 倍** —— 这与"≈3500 ULP"的**同一量级**，**故本项是"部分主因"**。

### 改动 ②：实现 Payne-Hanek 归约（**大参数**）

| 项 | 内容 |
|---|---|
| **位置** | 新增函数（建议紧随 `sin_cos_f64` 之后）＋ 在 `sin_cos_f64` 的归约处**分支**（现**行 203–206**） |
| **根因** | 现行归约用 `n = round_f64(x * TWO_OVER_PI)`（**行 203**）—— `x·2/π` 本身在 f64 下**舍入**；`x` 越大，`n` 的**绝对**误差越大 ⇒ `r = x − n·π/2` **灾难性抵消**。Cody-Waite 三段只补偿 π/2 的表示误差，**补不了 `x·2/π` 的舍入误差** |
| **做法** | 设 `|x| = m · 2^e`（`m` 为 53 位整数尾数）。用 `2/π` 的**多位（≥ 192 bit）常数表**与 `m` 做**整数乘**，取乘积的**小数部分高位** ⇒ 得 `n mod 8` 与 `r`（一次 `fma`/定点减即可） |
| **分支阈值（建议）** | `|x| < 2^20 · (π/2)` 用现有 **Cody-Waite**（快）；否则走 **Payne-Hanek**（准） |
| **依赖** | **纯整数运算 ＋ 一次定点减** ⇒ **零 `unsafe`、零依赖**（**C1／C3 不破**）；`core` 已提供 `f64::to_bits`／整数乘 ⇒ **不需要新增能力** |
| **常量表来源** | `2/π` 的高位十六进制位串（**须逐字复核**，不得凭记忆写入——**R71 精神：派生值不入文档，只引来源**） |

### 改动 ③：host 单测（**必须能测出改前的 3500 ULP**）

| 项 | 内容 |
|---|---|
| **位置** | `fmath.rs` 现有测试区（`sin_cos_match_std` 行 852／`sin_cos_large_argument` 行 865） |
| **新增/扩展** | ① **分段扫描**：`x ∈ [0, 2π]` 细步长 ＋ `x ∈ {1e3, 1e6, 1e9, 1e15, 1e300}` 等大参数点；② 与 **`std`** 逐点对照；③ **输出 `max ULP`（不只看平均）** |
| **★ 判据** | **改前**应能**复现 ≈3500 ULP**（**阳性对照**：证明测点确实覆盖了缺陷区；**若复现不出 ⇒ 测点选错**）；**改后** `max ULP` 应**显著下降**（目标 **≤ 4 ULP**，对齐 fdlibm 量级） |
