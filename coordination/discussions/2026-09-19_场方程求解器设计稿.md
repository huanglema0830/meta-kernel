## 2.2.2 数学基础

### (1) 主方程：泊松型场方程

```
        ∇²V(x, y) = ρ( SDF(x, y) )
```

| 符号 | 名称 | 含义 | 边界条件 |
|---|---|---|---|
| **`V`** | **可见性势** | 标量场；**`V = 0` 的等值面（零等值面）＝ 可见边界** | 见下方 (4) |
| **`SDF`** | 有符号距离场 | 到几何/语义边界的**带符号**距离（内负外正） | 由几何或 L5 诊断投影给出 |
| **`ρ(·)`** | **密度函数** | 把 SDF 映射成**源项**；决定"边界在哪里产生势" | **形式待裁**（§2.2.8 Q3） |

**为什么用泊松型（而不是演化型）**：

| 理由 | 说明 |
|---|---|
| **它是边值问题** | 显示要回答的是"**给定当前场 ⇒ 可见性是什么**"，不是"未来会怎样" ⇒ **椭圆型天然对口** |
| **等值面天然闭合光滑** | 泊松解是**调和＋特解**，`V=0` 曲面**不会自己断裂** |
| **一次求解得全局** | 对比 ray marching 的**逐像素**推进（成本 ∝ 像素数 × 步数） |
| **多重网格为它而生** | 多重网格的收敛理论**正是针对椭圆型** |

### (2) 密度函数 `ρ(SDF)` 的候选形式（**本稿给候选，裁定见 §2.2.8 Q3**）

| 候选 | 形式 | 特点 | 风险 |
|---|---|---|---|
| **甲 · 薄壳源** | `ρ = -δ_ε(SDF)`（把 `|SDF|<ε` 的薄层当源） | 直观：边界处"带电" | `δ_ε` 需正则化；`ε` 是一个**新常数**（须裁定） |
| **乙 · 软阈值** | `ρ = -tanh(SDF/ε)` 或 `-clamp(SDF/ε, -1, 1)` | **光滑、无奇异**，多重网格好收敛 | 边界**变宽**（`ε` 决定模糊度） |
| **丙 · 指示函数反相** | `ρ = -(1 - H_ε(SDF))` | `H_ε` 为软化阶跃 | 与乙近似，但**可解释为"体内不被看见"** |
| **丁 · 由 L5 诊断调制** | `ρ = ρ₀ · g(诊断结论)` | 把"场的语义"接进来（**显示状态可被 L5 式诊断**） | **增义风险**（须守 L6"呈现不增义"）⇒ 只能做**线性缩放**，不得改变结构 |

> **本稿倾向**：**乙（软阈值）**——因为多重网格**最怕高频奇异源**（`δ` 函数会把高频分量注入，粗网格无法表示 ⇒ 收敛退化）。**`ε` 取值须与粗网格步长绑定**（建议 `ε ≥ 1.5 × 粗网格格距`，理由：否则源项在粗网格上是**冲激**）。

### (3) NCA 的局部更新规则（**已核实**，见 §2.2.6 出处表）

**结构（Mordvintsev et al., Distill 2020）**：

```
  ┌─ 感知 Perception（固定核）──────────────────────────┐
  │  gx = Sobel_x * S      gy = Sobel_y * S             │   （3×3，对每个通道）
  │  P  = concat( S, gx, gy )                           │   （16 通道 ⇒ 48 维）
  └──────────────────────┬──────────────────────────────┘
                         ▼
  ┌─ 更新 Update（可学习，~8k 参数）────────────────────┐
  │  h  = ReLU( W1 · P )            （48 → 128）        │
  │  ΔS = W2 · h                    （128 → 16，W2 **初始化为 0**）
  │  S ← S + ΔS · mask                                  │   （mask：每格以概率 p 跳过；训练用 p = 0.5）
  └─────────────────────────────────────────────────────┘
                         ▼
  ┌─ 存活掩码 Alive Masking ────────────────────────────┐
  │  alive = maxpool_{3×3}(S[alpha]) > 0.1              │
  │  S ← S · alive                                      │
  └─────────────────────────────────────────────────────┘
```

**可直接搬进纯算层的四件事**（**都不需要训练**）：
1. **Sobel 感知**（固定核，纯算术）；
2. **MLP 前向**（权重表一旦拿到就是纯算术）；
3. **随机/异步掩码**（用确定性 PRNG ⇒ **可复现**，见下）；
4. **存活掩码**（max-pool ＋ 阈值）。

**★ 必须写死的两条工程约束**：

| # | 约束 | 理由 |
|---|---|---|
| **E1** | **随机掩码必须用确定性 PRNG**（不许用系统随机源） | ① **内核不得感知/动作**（机制 21：时钟/环境变量都属感知）；② 裸机上无可用的随机源；③ **判据必须可复现**（同种子 ⇒ 同结果） |
| **E2** | **训练不在内核内**（权重以 `const` 表进内核） | C1 零依赖 ＋ 内核无优化器/无反向传播 ⇒ **见 §2.2.4 与 §2.2.8 Q4** |

### (4) 边界条件

| 类型 | 用于 | 备注 |
|---|---|---|
| **Dirichlet**（`V = 0` on 边框） | 画面边框 ⇒ "外面不可见" | 简单、多重网格好收敛 |
| **Neumann**（`∂V/∂n = 0`） | 需要"场不流失"时 | 需特殊松弛（守恒形式） |
| **周期边界** | 若允许场在画面外延续 | **本稿不推荐**（会造出"无边界"的错觉） |

**本稿倾向**：**Dirichlet（画面边框 `V=0`）** —— 与"画面就是视窗"的直觉一致，且**省掉一次边界修正**。

### (5) Fourier 变换做全局通信（Fourier-NCA）

**问题（已核实）**：NCA 只与**直接邻居**通信 ⇒ **跨 100×100 图需 100 步**（本稿把这列为 §2.2.6 风险 R2）。

**解（已核实）**：**在 Fourier 空间做一次通信即可全局**（Kalkhof et al., arXiv:2401.06291）：
```
   场（图像空间）  ──FFT──►  截断的低频窗口（如 16×16，即中心四分之一）
                              │  在此窗口内跑 NCA（跨 16×16 需 32 步往返）
                              ▼
                   ══IFFT══►  图像空间：**全图一次性获得全局上下文**
```
⇒ **全局信息从"100 步"降到"1 次变换 ＋ 少量步"**。

**对本项目的三条硬约束（★ 必须写清，否则会埋雷）**：

| # | 约束 | 现状 |
|---|---|---|
| **F1** | **需要 FFT/IFFT** | ❌ **`fmath` 目前没有 FFT**（`meta-kernel-core-nostd/src/fmath.rs` 只提供 `sqrt/exp/ln/sin/cos/atan2/powi`）⇒ **须新增** |
| **F2** | **FFT 依赖 `sin`/`cos`** | ⚠️ 本项目 `f64 sin/cos` 有 **≈3500 ULP** 精度的**已登记缺陷**（根因：`cos` 缺 `r¹⁴/14!` 项、无 Payne-Hanek 归约）⇒ **精度影响必须先评估**（§2.2.8 Q6） |
| **F3** | **`alloc` 可用但要控量** | FFT 需要临时缓冲；`alloc` 属标准分发（D34-b，不破 C1），但**单帧上限 4 KiB**（`mem/global.rs:14`）⇒ 大 FFT **必须走静态数组**（`[f32; N]`）或**分块** |

### (6) 与「用户提供的演化型场方程」的对比（**用户指定项**；★ D-4 口径修订 2026-09-20）

| 项 | **用户提供的演化型场方程**（★ D-4：原称"灵境引擎"已撤销——**未取得任何出处**） | 本稿主方程 |

### (1) NCA 局部规则 —— **三引擎的"学习版"**（口径见姊妹稿 §2.9.2(3)）

| | 三引擎（现有） | NCA 局部规则 |

**本稿对"三引擎用在哪"的定位（与 Q11 一致）**：

| 用途 | 谁负责 |
|---|---|
| **空间形态的演化**（场怎么长） | **NCA 局部规则** |
| **时间节律的调度**（这一步推多快／用哪档节奏） | **三引擎**（Q8 裁定：固态→线性／液态→斐波那契／气态→斐波那契／能量态→指数） |

⇒ **两者分工不重叠**：三引擎管**时间**（节律），NCA 管**空间**（形态）。**这正好满足 Q10 前问"选择器不调制输入"**——三引擎只选节律，不改场。

**三种"要不要训练"的路线**（**本稿建议按此顺序评估**）：

| 路线 | 内容 | 权重来源 | 风险 |
|---|---|---|---|
| **甲 · 手写固定规则** | 完全不用神经网络：把 Sobel ＋ 阈值 ＋ 三引擎的固定映射当"局部规则" | **无需训练**（人写） | **表达力弱**（能长出什么完全靠手调）⇒ 可能"长不出有意义的图" |
| **乙 · 宿主离线训练 ＋ const 表** | 在宿主（std 侧、Python/Rust 均可）用梯度法训练 NCA；把权重**导出为 `const` 表**编进内核 | 离线训练 | ① 需新建**训练侧工具链**（仓库外）；② 权重**不可解释**；③ 换目标图要**重新训练＋重新提交** |
| **丙 · Vekua 式线性投影**（**本稿最看好**） | 把假设空间**限制在算子核内**（调和／傅里叶-贝塞尔基）⇒ 学习变成**严格凸最小二乘**，**一次线性投影**求解 | **一次最小二乘**（宿主侧，秒级） | ① ★ **已查证（2026-09-20 · D-5）**：该论文**只做了齐次椭圆** ⇒ 非齐次（有 `ρ` 源）**不被覆盖** ⇒ **采用「齐次主部 ＋ 源项特解」分解**（分解的**出处待补**）；② 需 Bessel 基（`fmath` 无）；③ 专利/许可未核 |

> ★ **为什么"丙"对本项目特别重要**：它把"**内核不能训练**"这道死结**从根上解开**——
> 不需要神经网络、不需要反向传播、不需要优化器：**一次线性代数解**就得到"精确嵌入物理先验"的基系数。
> 这**同时**满足 C1（零依赖）、机制 21（纯算）、L6（呈现不增义，因为是**投影**而非**创作**）。

### (2) 多重网格方法（MultiGrid）

**为什么必须用它**（这是 A1 的核心，不是优化项而是**可行性项**）：

| 方法 | 迭代次数（n×n 网格，Poisson） | 总复杂度 | 评价 |
|---|---|---|---|
| Jacobi / Gauss-Seidel（单层） | `O(n²)` 次 | **`O(n⁴)`** | 在 256×256 上**不可行** |
| Conjugate Gradient（无预条件） | `O(n)` 次 × `O(n²)`/次 | `O(n³)` | 一般 |
| **多重网格（V-cycle）** | **`O(1)` 次** | **`O(n²)` ＝ O(N)** | ★ **最优** |

```
        V-cycle（一个循环 = 下去 + 上来）
   细 n×n        ┌── 松弛×ν₁ ──┐
                  │              │ 限制 restriction（细 → 粗）
   粗 n/2         │        ┌─────┴── 松弛×ν₁ ──┐
                             │                    │ 限制
   更粗 n/4                  │             ...    │
   ...                        │  ← 最粗层：直接解（解析/少量 Jacobi）
   更粗 n/4                  ·  ← 插值 prolongation（粗 → 细）
   粗 n/2         ·───────┘     ＋ 修正 ＋ 松弛×ν₂
   细 n×n   ·──────────┘
```

**关键组件（**全部是纯算术，可进纯算层**）**：

| 组件 | 作用 | 实现要点 |
|---|---|---|
| **松弛（smooth）** | 消高频误差 | ★ **红黑 Gauss-Seidel**（可**原地**更新、**天然可向量化**、无数据依赖链） |
| **限制（restrict）** | 细 → 粗 | 全权重（9 点）或半权重（简单）；**必须是残差限制**（不是解限制） |
| **插值（prolong）** | 粗 → 细 | 双线性；★ **顺序必须是"松弛→算残差→限制→解粗→插值→修正→再松弛"** |
| **最粗层直解** | 终止递归 | 网格降到 2×2/4×4 时直接解（或多次迭代） |
| **残差判据** | 收敛停止 | `‖r‖_∞ / ‖ρ‖_∞ < tol`；**tol 须定为常数**（判据要可复现） |

**★ 必须写明的口径（防误用）**：
- **多重网格解的是"线性系统"**（`∇²V = ρ`）⇒ 若 `ρ` 依赖 `V`（非线性），需**外层不动点迭代**（V-cycle 作为内层）⇒ **复杂度分析要重新做**（§2.2.8 Q3）。
- **每一层的容器**：`[f32; W*H]` 静态数组（**不用 `Vec`** —— 因为**单帧 4 KiB 上限**，且层级尺寸编译期已知）。
- ★★ **网格尺寸必须是 `2^k + 1`（本稿最贵的一条"我踩过"）**：层尺寸按 **`w_l = ((w - 1) >> l) + 1`** 取（例 `33 → 17 → 9 → 5`），**不得**写成 `w >> l`。
  - **后果（实测，不是推断）**：用 `w >> l` 会让**粗层的两端边界点与细层错位**（细层 33 点的边界在 0 与 32；`33>>1 = 16` 只覆盖 0…15 ⇒ 右侧边界点丢失）⇒ 残差限制/插值全部错位。
    **修前**：1 次 V-cycle 残差**只降 71%**，且**层数越多越差**（粗层越多、错位越多）；**修后**：每 cycle 降 **8～60 倍**。
  - **非法尺寸一律返回 `BadDims`**（**不许"自动取整"**——静默改正会把错位藏起来，判据就失去意义）。
  - **实现落点**：`meta-kernel-core-nostd/src/field/poisson.rs::level_dims`（`pub const fn`，是本约束的**唯一权威实现**；任何新增调用方**必须 `import` 它**，不得自算 —— C19 同源）。
  - **判据**：`poisson.rs` 单测 `multigrid_needs_far_fewer_sweeps_than_single_level`（对照单层 GS 1024 全扫；实测 **113.8×**）＋ 非法尺寸用例返回 `BadDims`。

### (3) SIMD 优化

★ **本节是全文技术含量最高、也最容易踩坑的一节：Rust 里"SIMD"有三种，安全等级完全不同。**

| 路径 | 写法 | 是否需要 `unsafe` | 与 C1/C3/C9 的关系 | 本稿评价 |
|---|---|---|---|---|
| **甲 · 自动向量化**（编译器） | 写**标量循环**，但保证：① 连续内存 ＋ 步长 1；② 无分支（或用掩码）；③ **不别名**（`&mut` 唯一）；④ 循环次数编译期可见/可断言 | ❌ **不需要** | ✅ 完全合规 | ★ **先做这一条**。红黑 Gauss-Seidel ＋ SoA 布局**是很典型的可自动向量化形态**；实测加速比须基准测定 |
| **乙 · `core::simd`**（portable SIMD） | `#![feature(portable_simd)]` ＋ `f32x8` 等 | ❌ **不需要**（**安全 API**！） | ✅ 合规；但**需 nightly** | ★★ **boot 层已用 nightly**（`ci.yml:469-484`）⇒ 可行。**但**：`portable_simd` 仍是**不稳定特性** ⇒ 版本漂移风险，须在 CI 钉住 toolchain |
| **丙 · `core::arch` intrinsics** | `_mm256_add_ps` 等 | ✅ **需要 unsafe** | ⚠️ **必须走 C9**：专门边界文件 ＋ `// SAFETY:` ＋ 白名单 ＋ 用户确认 | ⚠️ **最后手段**。理由：intrinsics 是 `unsafe fn`（因 **CPU 特性检测**是安全契约：AVX 需运行期 `is_x86_feature_detected!`） |

**⇒ 本稿的 SIMD 策略（三句话）**：
1. **先写"可自动向量化"的标量内核**（甲）——**零 unsafe、零新依赖**；
2. **若实测不足**，再评估 **`core::simd`**（乙）——**仍是 safe**，代价是 nightly 特性稳定性；
3. **只在 A1/B 实测都达不到最低可用帧率**时，才申请 **C9 放行** intrinsics（丙）——**这与姊妹稿 §2.8"本期 0 处新增 unsafe"的结论一致**（**SIMD 不必 unsafe**）。

> ⚠️ **一条必须写明的风险（R35 口径）**：**`f32` 的 SIMD 宽度是 `f64` 的两倍**，而本项目已知教训是"**f32 分辨率会掩盖 f64 误差**"（`CONSTRAINTS`/记忆中的既有结论）。
> ⇒ 若 A1 的求解器用 `f32`，**残差判据必须按 `f32` 的 ULP 定**（不能照搬 `f64` 的 tol）；且**必须与一个 `f64` 参考实现对照**（host 侧单测）。

### (4) 缓存友好布局

| 决策 | 选项 | 本稿建议 | 理由 |
|---|---|---|---|
| **数组布局** | AoS（`[Px{r,g,b,a,...}]`） vs **SoA**（`[r...][g...][b...]`） | **SoA** | ① 通道数固定（16）；② **SIMD 载入需要连续同通道**；③ 多重网格的各层是**独立数组** |
| **遍历顺序** | 行优先 vs **分块（tile/Morton）** | **先不引入 Morton**（可读性优先），**但保证"多层同时驻留缓存"** | 多重网格的**粗层极小**（64×64×16×4B ＝ 256 KB，L2 级别；16×16 层 ＝ 16 KB，L1 级别）⇒ **天然的缓存友好**，无需 exotic 布局 |
| **双缓冲** | 原地 vs 两份 | **红黑 Gauss-Seidel 用原地**（省一半内存）；**NCA 必须双缓冲**（`S` 与 `S+ΔS`） | NCA 的更新依赖**同一时刻**的邻域 ⇒ 不能原地 |
| **对齐** | 4/16/32/64 B | **32 B 对齐**（AVX2 友好），用 `#[repr(align(32))]` 包装 | 与路径乙/丙匹配；路径甲也能受益 |

### (5) 动态稀疏网格（Dynamic Sparse Grid）

**动机**：画面大片区域"无结构"（如纯背景）⇒ 只在**有结构处**加密。

| 方案 | 内容 | 风险 |
|---|---|---|
| **甲 · 静态多层**（**本稿建议先做**） | 固定 128 → 64 → 32 → 16 → 8 → 4 → 2 的多重网格层级 | 无额外风险；**稀疏性由多重网格天然获得**（粗层就是"稀疏表示"） |
| **乙 · 按活动度细化** | 用 `|∇V|` 或 NCA 的 `alive` 掩码决定哪些块升级到细层 | ★ **判据难写**（结果依赖细化顺序 ⇒ 不确定性）；★ **复杂度爆炸**（块管理、邻接、边界补齐） |
| **丙 · 稀疏集合（`BTreeSet` 存活动块）** | 只存活动块 | 本项目已踩过 `HashSet` → `BTreeSet` 的坑（片3/片6）⇒ **可用但不宜作为首版** |

⇒ **建议**：**首版只做甲**（静态多层多重网格）；乙/丙**登记为增量**，须先解决"**确定性**"（判据前提）。

### (6) 复值场（幅度 ＋ 相位）

```
        Ψ = A · e^{iθ}        ⇒   存储为两条实数组：A[] 与 θ[]（SoA）
```

| 方面 | 说明 |
|---|---|
| **为什么用复值** | ① **相位**能表达"节律/干涉"——与**已有 `interference` 模块**（`phase_difference`／`detect` 驻点）**直接同构**；② 与 CEMI 那种"**波的相长/相消干涉**"的计算观**呼应** |
| **代价** | 存储 **×2**；算力 **×2～×3**（复数乘法 4 乘 2 加） |
| **★ 必须做的判据** | 与 `interference` 的**口径一致性**：对同一列波，本稿的相位差必须与 `interference::phase_difference` **逐值一致**（否则同一个概念出现两份实现 ⇒ 触 **C19**） |
| **降级方案** | 若不接受 ×2 代价 ⇒ 退为**单实值场**（放弃干涉语义，只留幅度） |
