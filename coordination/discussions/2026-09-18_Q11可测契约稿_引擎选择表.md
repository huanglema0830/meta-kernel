## 3. 选择表（**依 Q8 裁定 ＋ 行61 原文的严格不等式**）

**逐字引用**（`GENE_LIBRARY_DESIGN.md §2.1 行61`）：

```
  - 物态判据：`入/出 > 1.2 → 能量态；> 1.05 → 气态；≥ 0.8 → 液态；< 0.8 → 固态`
```

**逐字引用**（Q8 裁定，`BASELINE.md §10.6`）：

```
✅ **物态**（依 `GENE_LIBRARY_DESIGN` 行61 四档：入/出 >1.2 能量态；>1.05 气态；≥0.8 液态；<0.8 固态）。
拟补条文：**固态→线性／液态→斐波那契／气态→斐波那契／能量态→指数**
```

**合并结果**：

| # | `r` 区间 | 物态 | **引擎** | 是否「引擎切换点」 |
|---|---|---|---|---|
| 1 | `r < 0.8` | 固态 | **Linear** | — |
| 2 | `0.8 ≤ r ≤ 1.05` | 液态 | **Fibonacci** | ◀ **0.8 是切换点** |
| 3 | `1.05 < r ≤ 1.2` | 气态 | **Fibonacci** | **否**（物态变、**引擎不变**） |
| 4 | `r > 1.2` | 能量态 | **Expo** | ◀ **1.2 是切换点** |

> ★★ **本稿的关键结论**：**Q8 的四档映射到三引擎后，`1.05` 处"物态切换、引擎不切换"** ⇒
> **实际只有 2 个引擎切换点（`0.8` 与 `1.2`）**，不是 3 个。
>
> **与既有实测吻合**（V2 口径敏感性实测，`MATH_SPEC §5.1` 表）：
> `1.05` 处 单步口径 `0.000000`／稳态口径 `0.000000`／比值 **1×** —— 即**该点根本没有跳变**，
> 因为**两侧都是斐波那契**。这反过来印证了本表的正确性。

## 4. 判据（6 条，逐条可证伪）

| # | 判据 | 输入 | 期望 | 说明 |
|---|---|---|---|---|
| **D1** | 区间中点 | `r ∈ {0.4, 0.9, 1.1, 1.5}`（配同一 `x`） | `{Linear, Fibonacci, Fibonacci, Expo}` | 覆盖四个区间 |
| **D2** | **边界点（严格不等式）** | `r = 0.8` | **`Fibonacci`**（液态） | `≥ 0.8` ⇒ 液态 |
| | | `r = 0.7999999` | **`Linear`**（固态） | `< 0.8` ⇒ 固态 |
| | | `r = 1.05` | **`Fibonacci`**（**液态**） | 注意：`> 1.05` 才是气态 ⇒ **1.05 本身是液态** |
| | | `r = 1.0500001` | **`Fibonacci`**（气态） | 物态变、引擎不变 |
| | | `r = 1.2` | **`Fibonacci`**（**气态**） | 注意：`> 1.2` 才是能量态 ⇒ **1.2 本身是气态** |
| | | `r = 1.2000001` | **`Expo`**（能量态） | 切换点 |
| **D3** | **不切换性**（丙案直接推论） | `engine(1.05 − ε) == engine(1.05 + ε)` | `true` | 两侧同为 `Fibonacci` |
| **D4** | **不调制性**（丙案直接推论） | `f(r; x)` 在**同一物态内**取值 | **只由 `x` 决定** | 如 `f(0.9; x) == f(1.0; x) == f(1.05; x)` |
| **D5** | 域护栏 | `r = 0` / `r = 9`（clamp 上界） | `Linear` / `Expo` | 覆盖域外行为 |
| **D6** | **正反对照（自检）** | 把 D2 任一期望**故意写错**（如"`1.2 → Energy`"） | 判据**必须判红** | 证明判据**不是恒真**（防"自检与实跑同错"） |

> **口径提示（R35）**：以上 `ε` 取**可表示的最小邻域**建议 `1e-6`（f32 在 1.05 附近的 ULP 约 `1.19e-7`）；
> 具体取几，**须在实现时钉死并写进测试注释**，不得含糊。

## 7. 七要素（对「Q11 是否排期」本身的评估）

| 要素 | 内容 |
|---|---|
| **① 评估** | Q11 的前置（Q8／Q10）**已满足**；本稿把"入 CI"从"规则"改写为"**结果表**" ⇒ **从不可测变为可测**。但暴露 **U1／U2 两个未定项**（不裁定则测试无唯一期望值）。 |
| **② 优势** | ① **可测**（有限离散表，正反对照天然成立）；② **可复用**（同一表可用于单测／镜像／裸机断言，三处同源）；③ **可回归**（Q8 若改，表一改、判据自动跟上）；④ 与**机制 24（端点表）**同一设计模式 ⇒ 无需新范式。 |
| **③ 劣势** | ① **只覆盖"选择结果"**，不覆盖"切换平滑性"（丙案下后者本就无定义）；② 需**新建 `select_engine`**（新增代码面）；③ `ε` 取值需人工钉死。 |

| **⑥ 建议** | **先裁 U1／U2 → 再实现 `select_engine` → 再入 CI**。**不建议**跳过 U1 直接实现（会把未定语义固化进代码）。 |
| **⑦ 等待决策** | **U1（物态取哪一层）／U2（输出形态）／U3（是否补作用域句）／是否排期 Q11**。 |
