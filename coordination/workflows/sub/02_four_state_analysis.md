# 第 2 步 · 分析（四态场分析）

## 框架（公开）

**做什么**：把第 1 步的快照，**按四态分类**——存量＝基态／变量＝激励态／补充增量＝耦合态／创新增量＝新稳态。
四态是**同一时间的横切面**（第 3 步才是纵切面/时间轴），两者不可混用。

**输入**：第 1 步的**相空间快照**（必填）。缺少快照时不得直接对原始目标分析（会得到不可比的结论）。

**输出**：**四态分解表**——每个波动模式归入且仅归入一类，并给出该类的占比与主导项。

| 态 | 对应物理含义 | 判读要点 |
|---|---|---|
| 存量 | 基态 | 长期稳定、不随激励变化的部分 |
| 变量 | 激励态 | 由外部输入激发、随输入变化的部分 |
| 补充增量 | 耦合态 | 两两/多方作用的**中间产物**（本身不是终态） |
| 创新增量 | 新稳态 | 已稳定下来的**新**结构（区别于存量：它是"新"的） |

**与上下步的关系**：`第 1 步·罗列 → 本步 → 第 3 步·推演`
本步的输出是第 3 步的**初始条件**；四态划分错了，时间推演会沿错误初值发散。

**易错点（公开）**：
1. 把"补充增量"当成"创新增量"——前者是**过程**（耦合态），后者是**结果**（已稳定）。
2. 把"存量"与"创新增量"混同——判据是"**新不新**"，不是"稳不稳"。
3. 四态**不是互斥的量级排序**，不能按大小分配。
