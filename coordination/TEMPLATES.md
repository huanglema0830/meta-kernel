# 云内核项目 · 对话与报告模板

> 本文件是**三方（用户 / 顾问 / WorkBuddy）对话格式的单一约定**。
> 目的：把"每次重新对齐"变成"基准持续存在"，把"等人就停滞"变成"无响应自动推进"。

## 一、指令模板（顾问 → WorkBuddy）

```markdown
**基准**：vX.Y（先读 BASELINE.md）
**约束**：按 CONSTRAINTS.md 执行
**总规划定位**：[当前处于总路线图的哪个阶段/子任务]
**任务类型**：功能 / 修复 / 调研 / 清理 / 机制
**本阶段目标**：[一句话]
**任务内容**：[具体]
**验收标准**：[具体]
**汇报格式**：按报告模板
**版本号**：自动生成，不手写
```

**必须带的五个话术**：
1. 基准（BASELINE）
2. 约束（CONSTRAINTS）
3. 总规划定位
4. 本阶段目标
5. 汇报格式

## 二、报告模板（WorkBuddy → 顾问）

```markdown
**基准**：vX.Y（BASELINE已更新/未更新）
**总规划定位**：[本次任务在总路线图的哪个阶段]
**任务**：[本次任务]
**状态**：完成 / 部分完成 / 未完成
**验收对照**：[标准 vs 实测，逐条]
**未完成项**：[清单+原因]
**真实缺陷**：[本次发现的]
**三量台账**：
- 存量：[带入的]
- 变量：[本次任务]
- 补充增量：[新增的]
- 创新增量：[产出的]
**边界说明**：
- 本地跑过：[哪些]
- CI过：[哪些]
- 真实跑过：[哪些]
- 未验证：[哪些]
**需要用户决策**：[清单]
**下一步建议**：[清单]
```

**必须带的七个话术**：
1. 基准
2. 总规划定位
3. 状态
4. 验收对照
5. 三量台账
6. 边界说明（四种）
7. 需要决策 + 下一步

> **纪律**：三量台账与边界说明**不得省略**（对应 CONSTRAINTS C5/C6）；
> 报告里**不得出现手写"当前版本"**——版本一律来自 `git rev-list --count HEAD`（C2）。

## 三、无响应推进机制

```markdown
**优先级分级**：
- P0：阻塞性任务（不做后续全卡）
- P1：需要决策才能做
- P2：需要验证才能做
- P3：无需决策，可自主推进（调研/文档/测试/重构/修复/清理/基准维护/CI优化）
- P4：低优先级优化

**P1/P2 处理流程**：
T+0：发出请示
T+30min：第一次提示
T+2h：第二次提示（标注"超时未响应"）
T+4h：判定为"暂时无响应" → 转向P3清单
用户回来后：优先处理等待决策的事项

**P3 清单（不等人的活）**：
- 调研类：技术调研、依赖调研、方案对比、前沿搜索
- 文档类：文档撰写、注释补充、架构图更新、README更新
- 测试类：补充单元测试、增加覆盖率
- 重构类：代码清理、命名规范化、模块拆分
- 修复类：修复已知缺陷（不涉及架构变更）
- 清理类：技术债清理、警告消除、死代码移除
- 基准维护：BASELINE.md更新、ROADMAP.md更新、报告归档
- CI优化：加速CI、增加断言、优化缓存
```

> **与 C4 的关系**：C4 要求"改前先列清单、确认后执行"。**P3 项不含架构变更**，
> 故可在清单已列明的前提下直接推进；一旦触到 A 类改动（界面/核心交互/表结构/删除覆盖迁移/元规则），
> **降级为 P1 并停下等确认**，不得以"无响应"为由越界。

## 四、断裂接续机制

```markdown
**每次对话开始，WorkBuddy 按顺序读**：
1. coordination/README.md — 阅读顺序
2. coordination/BASELINE.md — 项目当前状态
3. coordination/CONSTRAINTS.md — 硬约束
4. coordination/TEMPLATES.md — 模板格式
5. coordination/ROADMAP.md — 总路线图
6. coordination/instructions/ 最新文件 — 当前任务
7. coordination/reports/ 最新文件 — 最近报告

**每次报告结束，WorkBuddy 必须**：
1. 更新 BASELINE.md（如果版本变了）
2. 把本次报告归档到 reports/
3. 把本次指令归档到 instructions/（如果是指令触发的）
4. 如有讨论记录，归档到 discussions/

**任何一方断裂，接续话术**：
> 继续云内核项目。读 coordination/ 下的最新状态。
> 告诉我：当前到哪一步、下一步是什么、需要我决策什么。
```
