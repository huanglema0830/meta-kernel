# 扰动模型（PERTURBATION_MODEL）v1.0

> 状态：**定稿 v1.0（2026-09-08）** ｜ 对应：LAYER_ARCHITECTURE（L0-L6）、SILA_IMPLEMENTATION
> 主旨：定义**内外扰动关系**与**地水火风（四行）映射**——扰动是点亮内核的燃料，四行是其"性"，各层守戒律地接纳它。

---

## 1. 扰动是什么

扰动（perturbation）= 打破一层"零/背景态"的触发输入。一次扰动 = 一个种子（0-1 域值）+ 语境（来源、时刻、tag 预留位）。

沿七层有不同叫法：L1 内称"种子/第一扰动"；L3 协议称"push"；L4 框架称"KernelEvent 的激发源"；L5 应用称"念头/意图"；L6 世界称"事件/回执"。

## 2. 内外扰动关系

### 2.1 定义

- **外扰（一阶）**：来自内核之外的注入——用户/世界/应用把一件事物送进系统（`POST /v1/push {seed}`）。外扰决定**何时点亮**。
- **内扰（二阶）**：内核演化过程中自发产生的再次触发——不来自外部，来自系统自身节奏：
  - 镜像回显（镜面观察 → 活动记录）；
  - 自然回归 e^-λ（储备波峰回落，非硬复位）；
  - 孪生配对（心流凿空：新输入命中历史模式之孪生 → 补充增量注入思考链）；
  - 真空重启（静默超阈后镜像池注入第一扰动 1.0）。
  内扰决定**演化方向与节律**。

### 2.2 关系法则

| 法则 | 内容 | 落点 |
|---|---|---|
| 外扰定亮、内扰定势 | 无外扰则内核停在当前演化（tick 由 push 驱动，不空转）；有外扰才进入新的推进，之后由内扰塑造轨迹 | npb push 驱动 / L3 不空转 |
| 外扰必经过滤 | 任何外扰先过 [0,1] 域过滤与负值拒（L2），违戒律即拒并计数 | sanitizer / gate_rejected |
| 内扰必可回显 | 内扰要么源于已有痕迹（镜像/习气），要么是确定性孪生配对——不允许"凭空冒出的新事实" | mirror/twin 机制 |
| 回归即新零 | 内扰中的自然回归/回融把储备或生命周期送回 0 附近的"待激发态"，为下一外扰准备背景 | e^-λ / 99→0 |
| 外扰可内化 | 外扰经演化后可成为痕迹/习气（内化），未来以内扰形式再次出现（风的记忆） | trace/habit |

### 2.3 闭环示意

```
外部（用户/世界）──外扰 seed──► L2 过滤（域/负值拒）──► L1 吸收
      ▲                                        │
      │                                  演化（物态/化合/闸门/镜面）
      │                                        │ 内扰（回显/回归/孪生）
      │                                        ▼
 世界反馈 ◄──L5/L6 外显 ◄──指令/状态 ◄──输出（L2 桥读）
```

## 3. 地水火风（四行）映射

内核痕迹系统已定义四类（trace：风=波动传递 / 火=化合转化·执取 / 水=连结流动 / 地=稳定结构·固化）。本模型把**扰动的"性"**映射到四行，让每个种子都携"行"属性，供上层（命名/意图）语义化使用：

| 行 | 性 | 典型扰动 | 内核行为倾向 | 生命周期表现 | 上层提示 |
|---|---|---|---|---|---|
| **风** | 波动·传递 | 新念头、灵感闪现、外部轻触 | 扩散、波形萌动、易触发驻点干涉 | 萌发带快步推进，显化快、驻留短 | 「新生·待观」 |
| **火** | 转化·执取 | 强烈情绪/需求脉冲、化合欲 | 化合吸收率高、闸门回收活跃、习气易成形 | 涌动/凝结带加速，可能早退（执取） | 「催化·防执」 |
| **水** | 连结·流动 | 例行事务、持续输入、关系流 | 平稳吸收、储备维持、液态表达 | 流淌带稳进，显化平顺 | 「延续·汇流」 |
| **地** | 稳定·固化 | 已固化模式/习惯、重结构输入 | 沉淀、固化、结晶、自我感增强 | 结晶/固化带驻留长，可能停滞 | 「沉淀·防固」 |

### 3.1 映射规则（一期）

- 种子本身是 [0,1] 数值（由 L5 文本指纹等确定性映射产生），"行"由**语境标注**给出：
  - L3/L5 请求预留 `element` 字段位（一期可为 null=自动）；
  - 自动判定（null 时，一期简化）：高频间隔输入→水；大幅脉冲（Δ≥0.4）→火；历史重复指纹命中→地；其余→风；
- 行属性不改变内核数学（内核仍按能量流演化——守"界面=投影"）；只供上层（L4 命名/意图、L5 日志）选择表达口吻与预期。
- 与孪生衔接：`twin_fingerprint=!fp` 配对在二期挂接——**地↔风互为孪生**（固化模式与新生念头互补），经命名 registry 预留的 twin 字段位表达（见 L4 v1.0 §4.1 规则 2.5）。

### 3.2 四行-痕迹-习气一致性

trace.rs 已实现 风/火/水/地 四类痕迹与习气聚合（同指纹聚合、强度饱和）——本模型的"扰动行属性"与内核痕迹四行**同词表不同层**：痕迹描述"已发生的模式"，扰动行描述"正在进入的触发"，经演化后扰动行并入痕迹分布（地属性扰动多→地性痕迹增）。命名 registry 因此共用四行词表（内外一致）。

## 4. 预留位与二期

- `tag`（L3 协议预留）：因果标注/多应用隔离；
- `twin`（L4 registry 预留）：孪生指纹匹配挂载位；
- `element`（本模型建议预留）：扰动行属性字段位（一期 null=自动，不占用实现）；
- 语义深度打分（文本→种子仅指纹映射）留二期（见 L5 v1.0）。
