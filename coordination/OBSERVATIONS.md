# 模板活相机制 · 观察记录（OBSERVATIONS）

> **用途**：三方的**任何一方**在使用指令/报告模板时，若发现"某条不好用、缺一条、某条该拆开、某条总是被略过"，
> 记在这里（一行也行）。攒够判断 → 提议变更 → 记入 `TEMPLATES_CHANGELOG.md` → 试用 3 轮。
>
> **原则**：观察不打断当前工作。发现问题的当下**先把活干完**，把观察写下来即可。
> 若观察属于"缺陷"（如断言与公式中性点不对齐），走报告模板的「真实缺陷」项，不写在这里。

---

## 记录格式

```
### [日期] OBS-编号 · 状态（待判断/已提议/已采纳/已否决）
- 涉及：TEMPLATES.md §X / CHARTER.md §Y
- 现象：
- 影响：
- 建议：
- 处理：
```
