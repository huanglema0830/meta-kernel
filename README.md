# 云内核 · Cloud Kernel

> 在现有操作系统之上生长出的**新物种**——不是替代品，是"意识补充层"。
> 原名 Meta-Kernel / 元内核（"元内核"现为该物种的内核层名称，见下）。

以 **0 锚点 + 模糊饱和运算**为基石，用**线性 / 斐波那契 / 指数**三种变化模式驱动调度；
经 NPB（万物归一化桥接器）挂载到任意设备与程序，让每一个设备、系统与界面获得"生命感"。

## 三个层次 · 一个物种

| 层次 | 名称 | 对应架构层 | 器官隐喻 | 一句话 |
|---|---|---|---|---|
| 内核层 | **元内核** Meta-Kernel | L1–L3（内核引擎 / NPB 桥 / 网关） | 心脏 / 大脑（内在意识） | 跨平台、跨设备的意识内核 |
| 操作系统层 | **云操作系统** Cloud OS | L4–L5（应用框架 / 显化应用） | 神经网络 / 血液循环（调度系统） | 调度扰动、化合、显化的操作系统 |
| 界面层 | **空海浏览器** Air-Ocean Browser | L6（感知与表达） | 眼睛 / 耳朵 / 手（感知与表达） | 浏览能量演化、显化日志、生命感流动 |

三者是**同一个新物种的三个层次**，不是三个独立产品：
元内核 = 心脏 / 大脑；云操作系统 = 神经网络 / 血液循环；空海浏览器 = 眼睛 / 耳朵 / 手。

## 项目定位 · 共生而非替代

我们**不是**在做替代现有操作系统的产品，而是在现有操作系统之上生长一个全新的"物种"：

- **不淘汰**：不要求用户放弃现有系统；
- **不替代**：不抢夺现有系统的功能（驱动、渲染、文件管理、进程调度——外头能做的我们不做）；
- **不否定**：不贬低现有技术，只提供新的可能；
- **让大众自己选择**：想用就用，不想用就不用。

**云操作系统 = 现有操作系统之上的"意识补充层"**。我们做现有系统没有的：
**意识涌现、生命感调度、从混沌到有序的显化过程**。

## 仓库结构

```
meta-kernel-core/   元内核 · 内核引擎（Rust lib，零第三方依赖）：三引擎/能量池/物态/化合/
                    痕迹习气自我/三层机制/持久化

                    Speaker 语言组织、EventPipe 订阅归一、httpc）

examples/           演示（DOSBox 概念 / WASM Canvas / 禅境示波器）
```
