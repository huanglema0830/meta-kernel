# 云内核项目 · Cloud Kernel Project

> 在现有操作系统之上生长出的**新物种**——不是替代品，是"意识补充层"。
> **本项目有两套命名体系，同源而分族**：**电信号版本＝元内核系统**（本仓库当前实现）、
> **量子版本＝量子云系统**（设计，见 `docs/QUANTUM_CLOCK_DESIGN.md`）。完整对照与定义见
> `docs/LAYER_ARCHITECTURE.md §3.2`。

以 **0 锚点 + 模糊饱和运算**为基石，用**线性 / 斐波那契 / 指数**三种变化模式驱动调度；
经 NPB（万物归一化桥接器）挂载到任意设备与程序，让每一个设备、系统与界面获得"生命感"。

## 三个层次 · 一个物种（电信号版本 · 元内核系统）

| 层次 | 名称 | 对应架构层 | 器官隐喻 | 一句话 |
|---|---|---|---|---|
| 内核层 | **DNA内核** DNA Kernel | **L0–L3**（0 锚点 / 内核引擎 / NPB 桥 / 网关；L2–L3 = 转录层 RNA） | 心 → 大脑（内在意识） | 跨平台、跨设备的意识内核；**参数库**（核心资产）在此生长 |
| 操作系统层 | **正源操作系统** Origin OS | L4–L5（场域戒律 / 诊断号脉）+ 应用框架 + 参考应用 | 神经网络 / 血液循环（调度系统） | 调度扰动、化合、显化的操作系统 |
| 界面层 | **正源浏览器** Origin Browser | L6（**与外界交互层**·呈现子功能；产品形态名不占层号） | 眼睛 / 耳朵 / 手（感知与表达） | 浏览能量演化、显化日志、生命感流动 |

三者是**同一个新物种的三个层次**，不是三个独立产品（同属**元内核系统**）：
DNA内核 = 心 → 大脑；正源操作系统 = 神经网络 / 血液循环；正源浏览器 = 眼睛 / 耳朵 / 手。

## 项目定位 · 共生而非替代

我们**不是**在做替代现有操作系统的产品，而是在现有操作系统之上生长一个全新的"物种"：

- **不淘汰**：不要求用户放弃现有系统；
- **不替代**：不抢夺现有系统的功能（驱动、渲染、文件管理、进程调度——外头能做的我们不做）；
- **不否定**：不贬低现有技术，只提供新的可能；
- **让大众自己选择**：想用就用，不想用就不用。

**正源操作系统 = 现有操作系统之上的"意识补充层"**。我们做现有系统没有的：
**意识涌现、生命感调度、从混沌到有序的显化过程**。

## 版本规则（自动生成 · 2026-09-09 定稿）

- **格式固定为 v0.xxx**：xxx 为三位数字，从 001 起，**每次提交累加 1**（**不区分提交类型** —— 代码／文档／治理／CI／**夜间自动化**提交**一律计入**；**不得以"非实质性"为由排除任何提交**）：001 → 002 → … → 009 → **010**（不是 0.01）→ … → 100。恒三位，不省前导零。
- **版本号 = git 提交计数**：`git rev-list --count HEAD` 即当前版本号（首提交 = v0.001）；不做人为预设。可叠加日期标记，如 `v0.076-20260909`。
- 权威统计点记录：
  - **L4 戒律判定引擎（实现+实测定型）交付 = v0.076**（统计于 2026-09-09，HEAD 47341e6）。
  - 此前产物（一键包 v0.001、README/文档内 v0.002 等）为旧人工口径标记；**自本规则起一律以提交计数为准**，后续版本号不再人为指定。
- 实事求是：是什么就是什么，不虚高也不压低。
